## 0. 位置づけ

「基調となる情緒」は3値選択＋自由記述、拡張可の項目（`../../input-items.md` グループ3）。
専用資料がないため、(a) `../../input-items.md` 自体が設計時の例として挙げた語、
(b) ジャンルの語彙作成で除外の代替として使われた情緒語、
(c) 本ツールの主要な用途（ゲームBGM・動画BGM）で需要が高いと判断した情緒語
の3種を材料とする。地域・文化の様式（`region-style.md`）と同様、専用資料がないため
V-03のような機械的な段階1〜4の適用はできず、根拠の区分を明示して記録する。

## 1. 材料の収集

| 語 | 出典 |
|---|---|

### 1-2. ジャンルの除外理由で使われた情緒語

`genres/cinematic.md` の Epic Music の除外（`substitutable`）で、
代替の組み合わせとして「情緒（壮大）」が明記されている（判断ポイント145）。

| 語 | 出典 |
|---|---|
| 壮大 | `genres/cinematic.md` の Epic Music の `exclusion.substitute`（「Cinematic ＋ 情緒（壮大）・強度」） |

`genres/country-folk.md` の Neofolk の除外にも「情緒（暗い・荘厳）」とあるが、
「暗い」は「明暗」軸の値そのものを指す略記であり、基調情緒の語として追加しない（判定の注記1）。

### 1-3. 本ツールの主要な用途から補った情緒語

ジャンルの除外理由に現れた情緒語は3つと少なく、実用に足りない。
`../../input-items.md` の想定用途（ゲームの戦闘BGM、動画のBGM）に照らし、
一般的な音楽・BGM制作で使われる情緒語から、明暗・強度と重複しない語を補った
（V-03のような専用資料に基づく段階審査ではなく、一般的な知識による判断。
ジャンルの Piedmont Blues 等と同型の扱い。`genres/blues.md` 判断ポイント86）。

| 語 | 選定理由 |
|---|---|
| 神秘的 | ファンタジー・ダンジョン探索など、ゲームBGMで需要が高い |
| 切なさ | ノスタルジー（郷愁）とは異なる、失恋・別れなど個人的な情感を指す語として区別が必要 |
| 高揚感 | 勝利・クライマックスの場面で需要が高く、単純な「強い」（強度軸）とは異なる質の高揚を指す |
| 優雅 | 舞踏会・貴族的な場面など、荘厳とは異なる上品さを指す |
| 不穏 | ホラー・サスペンス系のゲーム・映像BGMで需要が高く、単純な「暗い」（明暗軸）とは異なる不安定さを指す |
| 幻想的 | ファンタジー世界観のBGMで需要が高く、神秘的とは異なる夢見るような質感を指す |
| 温かみ | 日常シーン・癒し系BGMで需要が高く、単純な「明るい」（明暗軸）とは異なる親密さを指す |
| 勇壮 | 戦闘・出陣シーンで需要が高く、壮大（スケール感）とは異なる勇ましさを指す |

| # | 内容 |
|---|---|
| 1 | `genres/country-folk.md` の Neofolk の除外にある「情緒（暗い・荘厳）」の「暗い」は、明暗軸の値を指す略記であり、基調情緒の語としては追加しなかった。「荘厳」のみ1-1で採用済み |
| 2 | 1-3 の8語（神秘的〜勇壮）はジャンル資料・入力項目設計に明示的な出典がなく、一般的な知識による判断（`genres/blues.md` 判断ポイント86と同型）。専用資料がないため、段階3のような他語との個別比較（V-03 (ii)）は行っていない |
