## 段階3: 2資料以下の語の審査（V-03、V-15）

| 語 | 判定 | 理由 |
|---|---|---|
| Spectral Music | **追加** | C（現代クラシック派生）・S（現代音楽の「スペクトル」）。(i) 器楽で成立する。(ii) 倍音の分析から作る和声とゆっくり変化する音色の塊は和声の性格で、表す軸がない。Contemporary Classical は総称で、この和声を表せない（V-15。判断ポイント141） |
| Neoclassical | 追加しない | C・O。2つの意味を持つ語で、O は「新古典主義」（20世紀前半のバロック・古典派の形式への回帰）、C は現代クラシック派生の一覧に置く（ピアノと弦の静かな器楽を指す現代の用法とも読める）。前者は Modern Classical と副ジャンル Classical Period、後者は Contemporary Classical と編成（ピアノ・弦楽器）・情緒で代替できる（判断ポイント138） |
| Sonata | 追加しない | C・O（O は Symphony・Concerto と併記）。R-a 相当。楽曲の形式を表す語で、展開の形と編成（独奏楽器とピアノ）で表す（判断ポイント135） |
| Choral | 追加しない | C（Vocal / Choir。対応なし）・O（「Choral / Sacred music」）。R-a 相当。合唱という声の扱いを表す語で、入力項目「声の扱い」（言葉のない合唱）で指定する（判断ポイント140） |
| Operetta | 追加しない | C（Musical / Stage。対応なし）・S（形態による区分）。(i) を満たさない。歌唱と演劇を伴う音楽劇（判断ポイント140） |
| Gregorian Chant | 追加しない | C（Vocal / Choir、Gospel / Religious。対応なし）・S（中世音楽の説明「グレゴリオ聖歌」。§16 は対応なし）。(i) を満たさない。無伴奏の単旋律の聖歌（判断ポイント140） |
| Electroacoustic | 追加しない | C（現代クラシック派生、Experimental）・S（現代音楽の「電子音響」）。Contemporary Classical と副ジャンル Electronic・音質で代替できる。どちらも総称で、対象にない特徴を持ち込まない。G の本文「電子音響を取り入れた」は形容的な言及で、数えない |
| Tape Music | 追加しない | O（「Musique concrète / Tape music」。ambient）・G（本文「テープ音楽」。classical）の1対1。V-14 (5) により、アンビエント系より先に作成する本カテゴリで審査した。Musique Concrète で代替できる（O が併記） |
| 1資料のみの語（String Quartet、Suite、Prelude、Fugue、Nocturne、Etude、Overture、Tone Poem、Mass、Requiem、Oratorio、Ballet、Post-Minimalism、Aleatoric Music、Classical Crossover、吹奏楽・マーチ ほか） | 追加しない | 1資料のみ。語ごとの判定がないため辞典に記録しない（V-16）。吹奏楽・マーチは注記6 |

## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Opera | R-b | **除外**。歌唱と演劇で定義される語（S: 歌唱・管弦楽・演劇の総合芸術）。管弦楽の響きは Classical・Romantic と編成の規模で表す（判断ポイント140） |
| Symphony | R-a | **除外**（`other-axis`）。楽曲の形式（多楽章の管弦楽曲）を表す語。展開の形と編成の規模（大編成）で表す（判断ポイント135） |
| Concerto | R-a | **除外**（`other-axis`）。楽曲の形式（独奏楽器と管弦楽）を表す語。編成（主旋律を担う楽器、編成の規模）で表す（判断ポイント135） |
| Serialism | R-c | **除外**。G が Twelve-tone と併記しており、音像（無調の点描的な響き）は Twelve-tone に含まれる。資料数は3対3 の同数で、音の結果を指す名称として広く知られる Twelve-tone を残した（判断ポイント137） |
| Sacred Music | R-a | **除外**（`other-axis`、行き先は軸A）。宗教の場で定義される語で、音像は時代・地域で大きく異なる（`world.md` の Sufi Music と同型。判断ポイント140） |

次の適用も検討したが、適用しない。

- 時代様式の語（Medieval〜Contemporary Classical）への R-a（年代の軸）: 年代を名前に含むが、時代ごとに和声・形式・編成が別の様式として確立している。`rock.md` の Classic Rock（Rock と年代で代替）とは、年代を変えると音の組み立て方そのものが変わる点で異なる（判断ポイント134）
- Chamber Music への R-a（編成）: 編成の種類を表す語だが、4資料ともジャンルとして扱う（`jazz.md` の Big Band と同じ扱い。判断ポイント135）
- Classical と Classical Period の重なりへの R-c: 代表項目 Classical を広義（西洋芸術音楽全体）、Classical Period を狭義（古典派）として扱う（判断ポイント47・73 と同型。判断ポイント133）
- Medieval と Renaissance の重なり（G が併記）への R-c: 単旋律・初期の多声音楽と、成熟したポリフォニーで音像が別物（S の説明）
- Modern Classical と Contemporary Classical の重なりへの R-c: 20世紀前半〜中葉の様式と戦後以降の現代音楽で、時代と語法が異なる（判断ポイント136）
- Minimalism・Musique Concrète への R-a（技法・制作手法）: 4資料がジャンルとして扱い、反復や録音素材の加工という音の特徴がある（`reggae-caribbean.md` の Dub と同じ扱い）
- Impressionism への V-11: 美術の運動名に由来するが、音楽の様式（全音音階や平行和音）として定着している
