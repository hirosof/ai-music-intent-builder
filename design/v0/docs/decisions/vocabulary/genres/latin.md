## 段階3: 2資料以下の語の審査（V-03、V-15）

| 語 | 判定 | 理由 |
|---|---|---|
| Rumba | **追加** | C・S（latin 2/2）。(i) 打楽器の合奏で成立する。(ii) クラーベを基にしたキューバのルンバのリズムはリズムの型で、表す軸がない。Son Cubano はトレス（ギター）とトランペットを、Salsa はホーンセクションを持ち込むため代替にならない（V-15。判断ポイント112） |
| Norteño | **追加** | C・O（latin 2/2）。(i) アコーディオンとバホ・セクストの器楽で成立する。(ii) ポルカ由来の舞曲のリズムはリズムの型で、表す軸がない。Mariachi はバイオリンとトランペットの編成を持ち込むため代替にならない（V-15。判断ポイント112） |
| Nuevo Tango | **追加** | C・S（S は Tango の行でヌエボ・タンゴに言及）。(i) 器楽主体。(ii) ジャズやクラシック由来の和声と対位法は和声・旋律の性格で、表す軸がない。副ジャンル Jazz はスウィングや即興の様式を持ち込むため代替にならない（V-15。判断ポイント112） |
| Forró | **追加** | C・S（「フォルホー／アシェ／ファンキ・カリオカ」）。(i) アコーディオン、ザブンバ、トライアングルの器楽で成立する。(ii) バイアォンなどの舞曲のリズムはリズムの型で、表す軸がない。Samba は別のリズムの型と打楽器の編成を持ち込むため代替にならない（V-15。判断ポイント112） |
| Bolero | 追加しない | C・O。(i) を満たさない。ロマンティックな歌を中心とする様式（判断ポイント113。`pop.md` の Traditional Pop と同型） |
| Corrido Tumbado | 追加しない | C・G（「Corridos Tumbados (Regional Mexican)」）。R-b 相当。G の説明が「コリードの生楽器演奏にトラップの歌唱法やアティチュードを融合」で、器楽側はコリードの編成のまま、区別の主因が歌唱（判断ポイント115） |
| Regional Mexican | 追加しない | O（Mariachi・Norteño などを子に持つ小見出し）・G（Corridos Tumbados の括弧内。判断ポイント116）。メキシコの地方音楽の総称で、Mariachi・Norteño などの個別の語で代替できる |
| Latin Trap | 追加しない | C・O（O はレゲトンの子）。R-b 相当。器楽側は Trap と同じで、区別の主因が歌唱の言語（`pop.md` の Mandopop などと同型） |
| Nueva Cumbia | 追加しない | C・S（S の Cumbia の行の「のち電子化（ネオクンビア）」を数えた。判断ポイント114）。Cumbia と伴奏（シンセ）・リズムの担い手（ドラムマシン）・音質で代替できる。特徴を付け加える方向のみ |
| Nuevo Flamenco | 追加しない | C・O（O は Flamenco と併記）。Flamenco と伴奏（ベース・パーカッション）・音質で代替できる。特徴を付け加える方向のみ |
| 1資料のみの語（Latin Rock、Cha-Cha-Cha、Tropicália、Tejano、Banda、Axé、Funk Carioca、Latin Hip-hop、Dembow ほか） | 追加しない | 1資料のみ。語ごとの判定がないため辞典に記録しない（V-16）。Dembow は判断ポイント106 |

## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Latin | 保留 | **保留**。ジャンルの総称としても、他のジャンルに重ねる地域の形容（Latin Pop、Latin Jazz、Latin Trap の「Latin」）としても読める。判断ポイント31 により、両方に読める語は H-09 と合わせて決める（判断ポイント107） |
| Ranchera | R-c | **除外**。O・S が Mariachi と併記しており、器楽の音像は Mariachi の編成に含まれる。区別は主に歌の形式による（`jazz.md` の Traditional Jazz と同型。判断ポイント108） |
| MPB | R-b | **除外**。S の定義が「ブラジル大衆音楽の幅広い総称」のみで、C・O は名称のみ。音の系統を特定せず、区別が地域と言語による（`pop.md` の C-POP と同型。判断ポイント109） |
| Corrido | R-b | **除外**。G の説明が「語り歌」で、区別の主因は物語を歌う歌詞と歌唱。器楽の編成は Norteño などと共有する（判断ポイント110） |

次の適用も検討したが、適用しない。

- Mambo と Son Cubano の重なり（O・S が併記）への R-c: Mambo は大編成のホーンによる舞曲、Son Cubano は小編成の様式で同義ではない（判断ポイント111）
- Mariachi への R-a: 楽団の編成を表す語だが、3資料がジャンルとして扱う（`jazz.md` の Big Band と同じ扱い）
- Bachata と Merengue の重なり（S が併記）への R-c: S の説明が「それぞれ快活／ロマンティック」で、リズムの型も別物
- Flamenco への V-11（地域の形容）: 固有の形式名（判断ポイント31）。S はラテンアメリカではないとするが、配置は3資料とも latin
- Tango・Salsa・Cumbia への R-b: いずれも器楽の編成とリズムの記述がある（S のバンドネオン、C・O・G・S の舞曲としての扱い）
