## 段階3: 2資料以下の語の審査（V-03、V-15）

| 語 | 判定 | 理由 |
|---|---|---|
| Cajun | **追加** | C は world、O は cf で1対1 の同数。V-14 (5) により、先に作成する本カテゴリで審査した（判断ポイント97）。(i) アコーディオンとフィドルの器楽で成立する。(ii) ツーステップやワルツの舞曲のリズムはリズムの型で、表す軸がない。Folk と楽器・地域・文化の様式では舞曲の型を表せない（V-15） |
| Zydeco | **追加** | 所属と審査先は Cajun と同じ。(i) 成立する。(ii) ラブボードとアコーディオンによるシンコペーションしたリズムはリズムの型・奏法で、表す軸がない。Cajun は R&B・ブルース由来のリズムを持たず、Funk は生演奏のホーンやベースの様式を持ち込むため、代替にならない（V-15） |
| Neotraditional Country | 追加しない | C・O。Honky Tonk と年代・時代感で代替できる。特徴を付け加える方向のみ |
| Bro-country | 追加しない | C・O。Country Pop で代替できる（O が併記） |
| Western | 追加しない | C・S（「西部劇音楽」を数えた。判断ポイント99）。Country と地域・文化の様式（米国西部）で代替できる。S の説明は「西部イメージ」のみ。Western Swing はジャズのスウィングを持ち込むため代替に使わない（V-15） |
| Freak Folk | 追加しない | C・O（O は Anti-folk と併記）。Indie Folk と空間の質感・音質（エフェクト）・展開の形で代替できる。Psychedelic Rock はロックバンドの長い即興を持ち込むため代替に使わない（V-15。`rnb-soul.md` の Psychedelic Soul と同型） |
| Psychedelic Folk | 追加しない | C・S。Folk と空間の質感・音質（エフェクト）・展開の形で代替できる。C の Psychedelic の見出しは対応なし |
| Neofolk | 追加しない | C・S。Folk と情緒（暗い・荘厳）・リズムの担い手（打楽器）で代替できる。特徴を付け加える方向のみ |
| Singer-songwriter | 追加しない | C・O（G・S の「シンガーソングライター文化」は数えない。判断ポイント98）。R-b 相当。作詞作曲者本人の歌唱という歌い手の区別で、インストでは Contemporary Folk と差が出ない（O が併記） |
| Protest Song | 追加しない | G（出現のみ。Contemporary Folk の成り立ちの説明）・S（cf。派生の列挙）。区別が歌詞の主題による（R-c 相当。`hiphop.md` の Political Hip-hop と同型） |
| 1資料のみの語（Classic Country、Contemporary Country、Country Soul、Progressive Country、Cosmic Country、Progressive Bluegrass、Nashville Sound、Countrypolitan、Traditional Folk、Progressive Folk、Dark Folk、Acoustic、Anti-folk ほか） | 追加しない | 1資料のみ。語ごとの判定がないため辞典に記録しない（V-16）。G の本文「ナッシュビルの洗練されたプロダクション」は制作の記述で、Nashville Sound として数えない |

Folk Pop（C のみ。pop・cf）は `pop.md`、Folk Punk（C・O。rock）は `rock.md`、Cowpunk・Psychobilly（C のみ。rock）は作成済みのロック系の1資料の語として扱った。

## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Traditional Country | R-c | **除外**。O が Honky Tonk と併記しており、資料に音の違いの記述がない。資料数は3対3 の同数のため、様式を特定する名称の Honky Tonk を残し、時代を表す名称の Traditional Country を除外した（`jazz.md` の Traditional Jazz と同型。判断ポイント92） |
| Outlaw Country | R-c | **除外**。S の説明が「商業カントリーへの反抗」、G が「伝統回帰を掲げる」で、区別が姿勢による。音像は Honky Tonk と音質・強度で表せる範囲（`rnb-soul.md` の Southern Soul と同型。判断ポイント94） |

次の適用も検討したが、適用しない。

- Honky Tonk への R-a: S の説明は「酒場のカントリー」（場所）だが、名称の由来が場所であってもジャンル名として定着しており、3資料が様式として並べる（判断ポイント93）
- Contemporary Folk への R-c・R-b: G の説明は歌詞寄りだが、伝統的な民謡の編成とは音像が別物。広義の Folk と狭義の Contemporary Folk として扱う（判断ポイント95）
- Americana への R-a・R-c: S は「ルーツの総称」とするが、G・S とも一覧の語として並べ、ルーツ系の音像を指す。Alternative Country（O が併記）とは、一方が総称、一方がロック寄りの再解釈で同義ではない（判断ポイント96）
- Country Pop への R-a: S の「ポップチャート向け」は市場の記述だが、4資料がジャンルとして扱う。2資料の Pop Rock（`pop.md`）が段階3 で落ちたこととの差は、段階1 と段階3 の違いによる（判断ポイント38 と同型）
- Indie Folk への R-a: 流通を表す語を含むが、`rock.md` の Indie Rock と同じ扱い
- Alternative Country への R-c: 音像が特定の語に含まれない（S: インディー／ロック寄りの再解釈。`rock.md` の Alternative Rock と同じ扱い）
- Cajun への R-b: フランス語の歌唱を伴うことが多いが、区別の主因は器楽の編成と舞曲のリズム（判断ポイント97）
