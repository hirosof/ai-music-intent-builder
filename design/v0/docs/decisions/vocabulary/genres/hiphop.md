## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Gangsta Rap | R-c | **除外**。S の説明が「ストリートの暴力・貧困を描く」で、区別が歌詞の主題による。音像は Hip-hop に含まれる（`rock.md` の Anarcho-punk、`metal.md` の Viking Metal と同型。判断ポイント68） |
| Conscious Hip-hop | R-c | **除外**。区別が歌詞の主題による（同上） |
| East Coast Hip-hop | R-c | **除外**。区別が地域による。G の本文は東海岸で Boom Bap が定着したとしており、音像は Boom Bap に含まれる（判断ポイント67） |
| West Coast Hip-hop | R-c | **除外**。区別が地域による。G・S は西海岸の音を G-funk としており、音像は G-funk に含まれる（同上） |
| Southern Hip-hop | R-c | **除外**。区別が地域による総称（S はクランク・バウンスなどを含むとする）。音像は Hip-hop に含まれる（同上） |
| Emo Rap | R-b | **除外**。S の説明が「感情的な歌ものラップ」で、区別の主因が歌唱と歌詞（判断ポイント69） |
| Memphis Rap | R-b | **除外**。S はフォンクの由来として、G はフォンクの素材（音源）として挙げる。器楽の音像は Phonk に近く、Phonk との区別の主因はラップそのもの。区別を年代・地域と読んで R-c とする解釈も成り立つ（判断ポイント69） |

次の適用も検討したが、適用しない。

- Lo-fi Hip Hop への R-a: 質感（軸F）の語を含むが、4資料ともジャンルとして扱っている（`electronic.md` の Chiptune・Vaporwave と同じ扱い）
- Old School Hip-hop への R-a: 年代を含むラベルだが、S が音の特徴（シンプルなブレイク）を記述している
- Cloud Rap と Drill への R-b: S の説明は歌唱に触れるが（「歌ものラップ」「独特のフロウ」）、G・S に器楽側の特徴（夢見るような質感、変則的なスライドベース）の記述がある（`rock.md` の Emo と同型）
- UK Drill への R-c: 地域名を含むが、スライドする 808 ベースやシンコペーションしたハイハットなど、Drill（シカゴ）と音像が別物（判断ポイント52・70）
- Alternative Hip-hop への R-c: 音像が特定の語に含まれない総称で、R-c の対象にならない（`rock.md` の Alternative Rock と同じ扱い）

## 判定の注記

| # | 内容 |
|---|---|
| 1 | 表示順: 代表項目 → 初期・東西の系譜（Old School〜Alternative）→ 南部由来の系譜（Trap〜Phonk）→ 聴取向け（Lo-fi Hip Hop）。非表示の語は段階3 → 段階4a の表の順 |

| 3 | Trap は4資料とも主にヒップホップのトラップとして扱っているため、その意味で採用した。O はベース・ミュージックの節で「EDM トラップ」を別に挙げるが、V-14 (4) により同じ語として1回と数えた（`electronic.md` の集計どおり）。EDM トラップは「Trap ＋ 副ジャンル EDM」で表す。`term` は付けない（判断ポイント40・71） |
