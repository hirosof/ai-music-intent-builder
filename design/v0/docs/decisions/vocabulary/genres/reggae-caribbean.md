## 段階1: 3資料以上に登場する語

見出しの経路は V-14 (1) に従いすべて合わせて数えた。対応する見出しは C の「Reggae・Jamaica系」「Caribbean」、O の「レゲエ」、G の「ラテン／ワールド／レゲエ」（latin・world・rc に対応）、S の「12 カリブ海」。O の「ワールドミュージック ＞ カリブ・その他」は小見出しが対応なしのため、親の world だけが付く。表の「rc」は reggae-caribbean。

## 段階3: 2資料以下の語の審査（V-03、V-15）

| 語 | 判定 | 理由 |
|---|---|---|
| Calypso | **追加** | C は rc、O は world の1対1。V-14 (5) により、ワールド系より先に作成する本カテゴリで審査した（判断ポイント102）。(i) スティールパンなどの器楽でも成立する。(ii) カリプソのリズムはリズムの型で、表す軸がない。Reggae の系統の語はオフビートの型を持ち込むため代替にならない（V-15） |
| Soca | **追加** | 所属と審査先は Calypso と同じ。(i) 成立する。(ii) カリプソにインド系のリズムを取り入れた速い舞曲のリズムはリズムの型で、表す軸がない。「Calypso ＋ テンポ感（速い）」ではリズムの型の違いを表せない（V-15） |
| Zouk | **追加** | 所属と審査先は Calypso と同じ。(i) 成立する。(ii) 仏領アンティル由来のズークのリズムはリズムの型で、表す軸がない。Compas は別のリズムの型を持ち込むため代替にならない（V-15） |
| Compas | **追加** | 所属と審査先は Calypso と同じ（C「Compas」、O「Kompa」）。(i) 成立する。(ii) ハイチの中速の舞曲のリズムはリズムの型で、表す軸がない（V-15） |
| Ragga | 追加しない | C・O（O は Raggamuffin と併記）。Dancehall で代替できる。S が Dancehall をデジタルビートの様式とし、対象にない特徴を持ち込まない |
| Reggae Fusion | 追加しない | C・O。Reggae と副ジャンル（Pop・R&B など）で代替できる。融合名（`pop.md` の1資料のみの語の理由と同じ） |
| 2 Tone | 保留 | C（一覧）・S（§17 の「2トーン・スカ」。出現のみ）。レコード会社の名称そのものに由来し、RP-07 の扱いが未確定（`rnb-soul.md` の Motown と同型。判断ポイント104） |
| 1資料のみの語（Dub Poetry、Power Soca、Chutney、Ska Punk、Reggae Punk、Dembow ほか） | 追加しない | 1資料のみ。語ごとの判定がないため辞典に記録しない（V-16） |

## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Roots Reggae | R-c | **除外**。3資料とも名称のみで、Reggae と区別する音の記述がない。区別は主に年代と歌詞の主題（S が Reggae の特徴とするラスタファリの精神性）による。音像は Reggae に含まれる（判断ポイント103） |
| Lovers Rock | R-c | **除外**。3資料とも名称のみ。区別は主に歌詞の主題（恋愛）による。音像は Reggae と情緒・強度で表せる範囲（判断ポイント103。S の音の記述があった `rnb-soul.md` の Quiet Storm とは異なる） |

次の適用も検討したが、適用しない。

- Dub への R-a: 制作手法（残響・ディレイの強調）を表す語でもあるが、4資料がジャンルとして扱う（`electronic.md` の Chiptune・Vaporwave と同じ扱い。判断ポイント105）
- Dancehall への R-b: S の説明は「デジタルビート＋DJ／MC」で、器楽側の特徴（デジタルビート）がある（`hiphop.md` の Cloud Rap と同型）
- Reggaeton への R-b: G がデンボウのビートを核とする器楽側の特徴を記述している
- Ska・Rocksteady・Reggae の重なりへの R-c: S の系譜図で順に派生した様式として並び、テンポ感とリズムの型が互いに別物
- Mento への R-b: 民謡として歌を伴うが、器楽の編成（バンジョー、ハンドドラムなど）で区別される

| # | 内容 |
|---|---|
| 1 | 表示順: ジャマイカの系譜（Reggae → S の系譜図の順に Mento〜Reggaeton）→ 東カリブ・仏語圏（Calypso〜Compas）。代表項目がないため、Reggae を探しやすさのため先頭に置いた。非表示の語は段階3 → 段階4a の表の順 |

| 3 | Compas のラベルは C（Compas）と O（Kompa）の同数で、どちらも独立した項目のため、資料の略号順で先の C に合わせ、Kompa を別名にした（判断ポイント72 の規則が当たらない場合の仮の規則） |

| 5 | Calypso・Soca・Zouk・Compas は C では Caribbean、O ではワールドミュージックに置かれている。ワールド系の作成時に再審査しない（V-14 (5)） |
