## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| World Music | R-a | **除外**（`other-axis`、行き先なし）。S の説明が「市場ラベル」で、中身がきわめて多様。音の系統を表さない（`pop.md` の Adult Contemporary と同型。判断ポイント125） |
| Celtic | R-a | **除外**（`other-axis`、行き先は地域・文化の様式）。他のジャンルに重ねる地域の形容（`../README.md` §3-3、V-11、判断ポイント31・117。判断ポイント126） |
| Bollywood | R-b | **除外**。S の説明が「映画と一体の大衆歌謡」で、区別の主因は映画の歌（プレイバック歌唱）と用途。用途（映画）で定義される語として R-a とする解釈もある（判断ポイント129） |
| Filmi | R-c | **除外**。O・S が Bollywood と併記しており、同じ語を指す（`jazz.md` の Traditional Jazz と同型。判断ポイント129） |
| Sufi Music | R-a | **除外**（`other-axis`、行き先は軸A）。宗教の文脈で定義される語で、音像は地域によって大きく異なる（カッワーリーの声楽、トルコのナーイの器楽など）。V-11 の「用途で定義される大分類」を語に当てはめた（判断ポイント131） |

次の適用も検討したが、適用しない。

- Indian Classical・Hindustani Classical・Carnatic Classical の重なりへの R-c: Indian Classical は総称、Hindustani Classical と Carnatic Classical は楽器・装飾・リズム周期が異なる別の様式で、互いに含まれない（`blues.md` の Electric Blues と Chicago Blues と同型。判断ポイント130）
- Afrobeat と Afrobeats の重なりへの R-c: O が「別物として区別」と明記している
- Amapiano・Gqom・Kwaito の重なりへの R-c: いずれも南アフリカのハウス系だが、ログドラムのベース（Amapiano）、暗く割れたビート（Gqom）、遅いテンポのハウス（Kwaito）と音像が別物（判断ポイント52）
- Gamelan・Mariachi 型の R-a（編成を表す語）: Gamelan は合奏の名称でもあるが、2資料とも音楽の様式として挙げる（`jazz.md` の Big Band と同じ扱い）
- Afrobeats への R-b: G の説明に器楽側の特徴（ヨルバのリズムとファンク・ヒップホップ・ダンスホールの交錯）がある
- Arabic Classical・Klezmer への V-11（地域の形容）: 固有の形式・様式の名称として挙げられている（判断ポイント31）
