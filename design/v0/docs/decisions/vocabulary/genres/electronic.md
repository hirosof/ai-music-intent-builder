## 段階3: 2資料以下の語の審査（V-03、V-15）

| 語 | 判定 | 理由 |
|---|---|---|
| Melodic Techno | **追加** | (i) 器楽主体。(ii) 旋律の性格を表す軸がなく、Techno だけでは表せない。旋律的な既存の語（Trance / Progressive House）は長いビルドアップや壮大なパッドなど対象にない特徴を持ち込むため、代替にならない（V-15。`metal.md` の Melodic Death Metal と同型） |
| Psytrance | **追加** | (i) 器楽主体。(ii) 16分で転がるベースラインはリズムの型・奏法にあたり、表す軸がない（V-15。`metal.md` の Djent と同型） |
| Electro | **追加** | (i) 成立する。(ii) 当初の代替「Funk ＋ リズムの担い手（ドラムマシン）」は、Funk が生演奏のベースやホーンを持ち込むため成り立たない（V-15）。808 のシンコペーションはリズムの型で、Electronic と他の軸でも表せない。語の曖昧さは `term` で扱う（注記3） |
| Breakbeat | **追加** | (i) 成立する。(ii) 分割ビートはリズムの型で、表す軸がない。Jungle / Drum and Bass は高速のテンポ帯を持ち込むため、中速の Breakbeat の代替にならない（V-15） |
| Happy Hardcore | **追加** | (i) 成立する。(ii) 当初の代替「Gabber ＋ 明暗」は、Gabber の強く歪んだ攻撃的なキックを打ち消す必要があり成り立たない（V-15）。中立な上位語（Hardcore Techno）は採用していない |
| Electro House / Future House | 追加しない | House と強度・音質で代替できる |
| Tech House | 追加しない | House と副ジャンル Techno。両方の特徴が対象に含まれる |
| Afro House | 追加しない | House と地域・文化の様式で代替できる |
| Big Room House | 追加しない | EDM（狭義）で代替できる。S は EDM がビッグルームを指すとしている |
| Detroit / Minimal / Industrial Techno | 追加しない | Techno と、年代・地域、展開（一定を保つ）と編成の規模、音質・強度で代替できる |
| Dub Techno | 追加しない | Techno と空間の質感（深い残響・ディレイ）、展開で代替できる。副ジャンル Dub はレゲエのリズムを持ち込むため代替に使わない（V-15） |
| Uplifting / Progressive Trance | 追加しない | Trance と情緒・展開で代替できる |
| Vocal Trance | 追加しない | R-b 相当 |
| Goa Trance | 追加しない | Psytrance と年代で代替できる（O が併記） |
| Liquid Drum and Bass / Neurofunk / Techstep / Jump-up | 追加しない | Drum and Bass と情緒・音質・強度で代替できる |
| Breakcore | 追加しない | Jungle とテンポ感（より速い）・強度で代替できる。特徴を付け加える方向のみ |
| Hardcore Techno | 追加しない | Gabber で代替できる（O が併記） |
| Frenchcore / Speedcore | 追加しない | Gabber とテンポ感・強度で代替できる。特徴を付け加える方向のみ |
| Brostep / Riddim | 追加しない | Dubstep と強度・音質で代替できる |
| Drumstep | 追加しない | Drum and Bass と Dubstep。両方の特徴が対象に含まれる |
| Big Beat | 追加しない | Breakbeat と副ジャンル Rock、音質で代替できる |
| 2-step | 追加しない | UK Garage で代替できる（O が下位に置き、2ステップのリズムを共有する） |
| Hi-NRG | 追加しない | 副ジャンル Disco（R&B・ソウル系で採用。`rnb-soul.md`）とテンポ感・伴奏（シンセ）・年代で代替できる。Eurodance は90年代の様式を持ち込むため代替に使わない（V-15） |
| Glitch | 追加しない | IDM と音質で代替できる |
| Downtempo / Chillout | 追加しない | Electronic とテンポ感・情緒で代替できる。Chillout は情緒・用途寄りの語 |
| Trip Hop | 追加しない | 主ジャンル Hip-hop（ヒップホップ系で採用。`hiphop.md`）と、情緒（暗い）・テンポ感・空間の質感・音質で代替できる。ラップはインストでは生じないため、持ち込まれる特徴にならない |
| Chillwave | 追加しない | Dream Pop と伴奏（シンセ）・音質（ローファイ）で代替できる。Synthwave は疾走感のある様式を持ち込むため代替に使わない（V-15） |
| Retrowave | 追加しない | Synthwave で代替できる（O が併記） |
| Darksynth | 追加しない | Synthwave と情緒（暗い）・強度で代替できる |
| Future Funk | 追加しない | 副ジャンル Disco と、音質（フィルターやサンプリング的な加工）・明暗・年代で代替できる。Vaporwave は遅く漂う質感を持ち込むため代替に使わない（V-15） |
| Moombahton | 追加しない | 副ジャンル Reggaeton（レゲエ・カリブ系で審査予定。所属は latin 3/4・reggae-caribbean 3/4 で、先に作成するレゲエ・カリブ系で審査する。V-14 (5)）と EDM、テンポ感で代替できる |
| 8-bit | 追加しない | 過半数なし（C・O とも対応なし）。Chiptune で代替できる（O が併記）。質感寄りの語 |
| Drift Phonk | ここでは審査しない | 過半数なし（C は hiphop、G は electronic）。G が Phonk と併記しているため、ヒップホップ系へ送る |
| 1資料のみの語（Club Music、Electronica、Electroclash、Footwork、Eurobeat、Mallsoft、Tech Trance ほか） | 追加しない | 1資料のみ。語ごとの判定がないため辞典に記録しない（V-16） |

## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Grime | R-b | **除外**。資料の説明が「UKガレージとラップの交差」「クラブ／MC文化」（S）で、区別の主因が歌唱にある。歌あり対応時に再評価する（判断ポイント49） |

次の適用も検討したが、適用しない。

- Chiptune と Vaporwave への R-a: 資料が音源や加工ではなく、ジャンル・美学として扱っている
- Eurodance と Future Bass への R-b: 前者はシンセのリフ、後者のボーカルチョップはサンプル素材であり、器楽側の特徴が主
- Deep House / Progressive House / Jungle / Gabber への R-c: 上位や併記の語と音像が別物（判断ポイント52）
