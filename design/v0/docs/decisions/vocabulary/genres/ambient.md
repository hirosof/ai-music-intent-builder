## 段階3: 2資料以下の語の審査（V-03、V-15）

| 語 | 判定 | 理由 |
|---|---|---|
| Dark Ambient | 追加しない | C（Ambient。Gothic / Dark は対応なし）・O（Ambient の子）。Ambient と情緒（暗い）で代替できる。特徴を付け加える方向のみ |
| Space Ambient | 追加しない | C・O（「Space ambient / Drone ambient」）。Ambient と空間の質感（広大な残響）で代替できる |
| Drone Ambient | 追加しない | C・O（同上）。Ambient と副ジャンル Drone で代替できる。両方の特徴が対象に含まれる |
| Lowercase | 追加しない | C（Experimental）・O（「Lowercase / Field recording」）。Ambient と強度（ごく控えめ）・編成の規模（最小）で代替できる |
| Field Recording | 追加しない | C（Experimental）・O（同上）。R-a 相当。録音した環境音という音の素材を表す語で、音の構成（軸D）や自由記述で指定する（判断ポイント151） |
| 1資料のみの語（Tribal Ambient、Isolationist Ambient、Ambient Electronic、Ambient Techno、Ambient House、Ambient Dub、Nature Sounds、Soundscape、Neoclassical New Age、Free Improvisation、Harsh Noise、Noise Wall、Acousmatic、Microsound、Sound Collage、Onkyo、Plunderphonics、Hypnagogic Pop ほか） | 追加しない | 1資料のみ。語ごとの判定がないため辞典に記録しない（V-16）。Neoclassical New Age は判断ポイント152 |

C の「New Age / Healing」の一覧のうち、Meditation Music、Healing Music、Relaxation Music、Yoga Music、Spiritual Music、Nature Music は用途で定義される語で、軸A の語彙で扱う（V-11）。
C の Easy Listening と S の §16「イージーリスニング／ムード音楽」（いずれも対応なし）は、配置のない用途の語として審査しない（`cinematic.md` の Soundtrack と同じ扱い。判断ポイント146）。

## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Experimental | R-a | **除外**（`other-axis`、行き先なし）。実験的という姿勢を表す横断的な形容で、音の系統を特定しない（Experimental Rock、Experimental Hip-hop のように他のジャンルに重ねて使われる）。V-11 の「横断的な分類」を語に当てはめた（判断ポイント150） |
| Avant-Garde | R-a | **除外**（`other-axis`、行き先なし）。O が Experimental と併記し、同じく前衛という姿勢を表す横断的な形容（判断ポイント150） |

次の適用も検討したが、適用しない。

- New Age への R-a（用途: 瞑想・ヒーリング）: S の説明が「瞑想・ヒーリング寄りの穏やかな電子／アコースティック」で、用途に寄るが音の方向（穏やかな電子音とアコースティック楽器）も記述している
- Noise への R-a（質感）: 音そのものを素材にする様式として、3資料がジャンルとして挙げる
- Drone と Ambient の重なりへの R-c: Drone は持続音を中心に据える様式で、Ambient より音像が限定され、別物（判断ポイント52）
