## 段階1: 3資料以上に登場する語

## 段階3: 2資料以下の語の審査（V-03、V-15）

| 語 | 判定 | 理由 |
|---|---|---|
| Funk Rock | 追加しない | `rock.md` から送られた語（rnb-soul 2/2）。Funk と副ジャンル Rock で代替できる。両方の特徴（シンコペーションしたベースとドラム、歪んだギター）が対象に含まれる |
| Psychedelic Soul | 追加しない | Soul と空間の質感・音質（エフェクト）・展開で代替できる。Psychedelic Rock はロックバンドの長い即興を持ち込むため代替に使わない（V-15） |
| Trap Soul | 追加しない | Contemporary R&B と副ジャンル Trap で代替できる。両方の特徴が対象に含まれる |
| Alternative R&B | 追加しない | Contemporary R&B と情緒（暗い）・空間の質感・音質で代替できる。特徴を付け加える方向のみ |
| Doo-wop | 追加しない | (i) を満たさない。G・S とも声のハーモニーを中心とする様式として扱う |
| 1資料のみの語（Deep Soul、Progressive Soul、Blue-Eyed Soul、Northern Soul、Memphis Soul、Hip-Hop Soul、Deep Funk、Jazz-Funk、Free Funk、Go-Go、Minneapolis Sound、Boogie ほか） | 追加しない | 1資料のみ。語ごとの判定がないため辞典に記録しない（V-16） |

## 段階4a: 規則による刈り込み

| 語 | 規則 | 扱い |
|---|---|---|
| Gospel | R-b | **除外**。S の説明が「コール＆レスポンス、熱のこもった歌唱」で、区別の主因が歌唱。器楽側（オルガン・ピアノ）の特徴は資料に記述がない。宗教の場で定義される語として V-11（用途）に当たるとする解釈もある（判断ポイント76） |
| Southern Soul | R-c | **除外**。区別が地域による。S は「デトロイトの洗練 vs 南部の生々しさ」とするが、この差は音質・強度で表せる範囲で、音像は Soul に含まれる（`hiphop.md` の Southern Hip-hop と同型。判断ポイント77） |
| Motown | 保留 | **保留**。レコード会社の名称そのものであり、RP-07（実在の固有名詞を使わず特徴に分解する）の対象になるかが未確定。音の特徴は Soul と年代・時代感などで表す（`pop.md` の Vocaloid の保留と同じ扱い。判断ポイント75） |

次の適用も検討したが、適用しない。

- Contemporary R&B への R-b: G にドラムマシンやシンセサイザーを取り入れた器楽側の特徴の記述がある
- Quiet Storm への R-a: 由来はラジオの番組形式だが、S が「遅いテンポのロマンティックなR&B」と音の様式として記述している（`pop.md` の Adult Contemporary と異なる。判断ポイント78）
- P-funk への RP-07 の考慮: 団体名に由来するが、団体名そのものではなくジャンル名として定着している（G-funk の語源でもある。判断ポイント79）
- Nu-disco への R-c: 電子音楽の制作手法による現代的な音像で、Disco と別物
- R&B と Contemporary R&B の重なりへの R-c: 代表項目 R&B を広義（R&B・ソウル・ファンクの系譜全体）、Contemporary R&B を狭義として扱う（`electronic.md` の Electronic と EDM と同型。判断ポイント73）

## 判定の注記

| # | 内容 |
|---|---|
| 1 | 表示順: 代表項目 → 1960〜70年代の系譜（Soul〜Disco）→ 1970年代以降の R&B（Quiet Storm〜Neo Soul）→ Nu-disco。非表示の語は段階3 → 段階4a の表の順 |
| 2 | 代表項目は R&B とした。R&B・Soul・Funk はいずれも4資料の最上位の見出しに現れ、数では決まらない。カテゴリのラベル（R&B・ソウル系）の先頭であることと、S が R&B の意味がソウル・ファンク・コンテンポラリーR&B へ移ったと説明していることによる（判断ポイント73） |
| 3 | R&B と Rhythm & Blues は V-01 の表記揺れ（略称と正式名称）として同じ語に数えた。C は両方を別の項目として並べ、O は「Rhythm and blues（古典）」を別に挙げるが、G・S は同じ語として歴史を説明している。1940〜50年代の古典的な R&B は「R&B ＋ 年代・時代感」で表す（判断ポイント73） |
| 4 | O の「Electro（エレクトロ／エレクトロファンク）」と C の Funk の一覧の「Electro-Funk」は、`electronic.md` で Electro の別名とした語。同じ語として数えても Electro の所属は electronic（2/2）で変わらない |
| 5 | Funk Metal（C のみ。metal・rnb-soul）は、作成済みのメタル系を含む1資料の語のため記録しない（`hiphop.md` の注記9 と同じ扱い） |
| 6 | ラベルの綴り（V-06）: `P-funk`（C・O・G は `P-Funk`）、`Nu-disco`（ハイフン 2/3）、`Neo Soul`（分かち書き 2/3）、`Doo-wop`（G の `Doo-Wop`）はハイフンの後を小文字にする規則による |
