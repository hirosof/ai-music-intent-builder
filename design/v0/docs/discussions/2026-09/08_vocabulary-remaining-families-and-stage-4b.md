## 2. H-09（`Japanese traditional` と `Japanese style`）の検証

### 経緯

1. 利用者が Suno で各スタイル4曲ずつ生成し、ブラウザ内で完結する音響分類ツールで解析（`examples/suno-test-02-jp-traditional-vs-style.md` §1〜§5）
2. Claude が一次判定: 差の傾向はあるが弱い（§6）。判定規則を**結果を見る前に固定**（§7）
3. 手動の聴取では正確に判断できるか不安があるとの指摘を受け、PC 内で完結する解析スクリプトを作成（`tools/suno-audio-compare/`）
4. 実行結果は **判定不能**（§9）

### 結果と副産物

| 項目 | 内容 |
|---|---|
| H-09 | **判定不能**。事前に固定した主指標6個のうち分離0個。探索的には style の4曲中3曲でピアノ・電子音・低域の打楽器が増える傾向 |
| 規則の限界 | 4曲対4曲で「逆転1組まで」という分離の基準は、1曲の外れで全指標が崩れる。再検証案（H-09b）では6曲・80%に緩める |
| CLAP | 類似度がほぼ0で測定不良の疑い。実行ログでは重みは正常に読み込まれており、原因は未特定 |
| H-08 | **反証**。曲名は入力スタイル単位ではなく**生成リクエスト（1回2曲）単位**で決まる |
| H-02 | 追加の観察。書き換えのない条件でも、スタイルの内容で曲名の言語が変わる |

### 設計への反映

判定不能のため `presets.md` 判断ポイント4 は現状維持とした。その後、利用者の提案で下記の構造変更につながった。

## 3. 「様式の寄せ方」の新設（判断ポイント117、`input-items.md` §4 の5〜7）

### 提起

> 「Japanese traditional」と「Japanese style」を別に持つよりも、別のオプションとして「traditional」「style」などを選択できたほうが良いか？
> そうすれば「Chinese traditional」なども簡単に対応できる。

### 検討

| 案 | 内容 | 評価 |
|---|---|---|
| A | 地域の項目ごとに寄せ方を持つ | 保存データの `choices` の値をこの項目だけ変える必要がある |
| **B（採用）** | 独立した項目「様式の寄せ方」を作り、「使用する」の地域すべてに適用する | 保存データの形を変えない。情緒を基調・強度・明暗に分けたのと同じ形 |

さらに利用者の提案で3択（〜風 / 伝統寄り / 現代寄り）とし、③の既定は「〜風」とした。
「EDM traditional」のような語ができる心配は、寄せ方が地域・文化の様式にだけ掛かることで解消する。

### 波及

- `presets.md` §2-4 の例（和風（伝統音楽）/ 和風（現代的））を差し替え、P-05（英語の組み立て方）を追加
- 判断ポイント107（語「Latin」の保留）は、地域・文化の様式の1項目として扱う方向で再判定する見込み
- 入力項目は約28→29項目

## 4. 段階4b の進め方（判断ポイント154〜161、`vocabulary/stage-4b-plan.md`）

### 提起された問題

16カテゴリ完了時点で、既定で表示する語は **205語**。判断ポイント14 の目安（80〜120）を大きく超えた。

内訳: 段階1（3資料以上）164語、段階2（Suno の実績）3語、段階3（2資料以下で追加）38語。
**段階3 の38語をすべて非表示にしても164語**で、目安に合わせるには3資料以上の語も数で削る必要がある。

### 決定

| 論点 | 決定 |
|---|---|
| A. 目安 | 総数の目安をやめ、カテゴリごとの上限（V-13 の25）だけを残す。数による非表示は**選択 UI の試作後**にカテゴリごとの行数を見て決める |
| B. 規則による非表示 | 重なりの組の見直しだけ実施。根拠の弱い2資料の語は候補一覧のみ |
| C. 1資料の語の追加 | 軸A（用途）の語彙を作るときに再検討 |
| D. R&B の代表項目 | 維持（S の R&B の表が表示中の10語をすべて含む） |
| E. Suno での確認 | 現時点では行わない |

### 実施結果

- 重なりの5組（Drill / UK Drill、Swing / Big Band、Electric Blues / Chicago Blues、Indian Classical 三語、Modern / Contemporary Classical）はいずれも両方表示。**非表示にした語はない**
- 「近い系統」の警告ペアリストのジャンルの初版を作成（6組。`vocabulary/warning-pairs.md`）
- B2 の候補一覧（34語。うち資料に音の記述がない語31語）を `stage-4b-plan.md` §8-3 に記録
