## 2. 数え方（Claude Code。2026-10-28）

スクリプトで数えた（Python。数え方は次のとおり。設計スレッドの計測の定義〔漢字＝CJK統合漢字と「々」、振り仮名＝「漢字の連なり＋送り仮名」の直後の「（ひらがな）」〕に合わせた）。

- **歌詞の取り出し**: 回答の中の、構成タグ（`[Verse]` のように、行に `[英字]` だけがあるもの）を含むコードブロックのうち、最も長いもの。字下げされたコードブロックも取り出す（C2 の Gemini、C6 の ChatGPT は回答全体が字下げされていた）。C0 の Opus 5.5 は、ファイルが歌詞だけ（コードブロックなし。516字）だったため、ファイル全体を歌詞とした。構成タグの行は数えない
- **漢字**: CJK統合漢字（U+4E00〜U+9FFF）、拡張A（U+3400〜U+4DBF）、「々」
- **振り仮名**: 「漢字の連なり＋送り仮名（ひらがな）」の直後に続く「（ひらがな・長音）」。1か所を1と数える（「揺（ゆ）れる」も「神秘（しんぴ）」も1）。半角の括弧「(…)」の形も別に数えた（0件だった）
- **振り仮名のない漢字**: 直後（送り仮名の後）に振り仮名が続かない漢字の連なりの、漢字の字数
- **漢字の割合**: 漢字 ÷（漢字＋かな）。かなはひらがな・カタカナ・長音「ー」。振り仮名の括弧の中は除く

## 4. 数えていないもの（教訓4-40）

- 振り仮名の**読みの正誤**（例: 判断ポイント49 の根拠にある「音頭」→「おんとう」）は数えていない。読みの誤りは、人が文脈で判断する（`rendered-14` の VK-3）
- 送り仮名の前に振り仮名を置いた形（「揺れる（ゆれる）」の型）は、この数え方では「振り仮名」に数える（括弧が漢字の連なり＋送り仮名の直後に続くため）。形の揃い方は数えていない
- 歌詞以外（スタイル欄・曲名案・注意事項）の漢字
- Suno での歌われ方（利用者が、振り仮名つきの歌詞がフルサイズの生成で意図どおりに歌われることを確かめた。判断ポイント49 の根拠）
