# Suno 検証 01: 粒度とバリエーションの組み合わせ（H-07）

- 最終更新: 2026-09-16
- 目的: `research/open-questions.md` H-07 の判定
- 状態: **検証済み（2026-09-16、§9）**

H-07: 基本プロンプト（短い）＋バリエーション標準 の組み合わせは、
詳細プロンプト＋オフ と同等以上の結果を出し得る。

この仮説は `principles.md` R-17（出力する粒度）の前提になっている。
判定結果によって、粒度の既定値とバリエーション設定の推奨が変わる。

---

## 1. なぜ判定基準が必要か

「どちらが意図に近いか」は、そのままでは比較できない。聴いた印象は生成ごとにぶれるうえ、
比較する2つが別の曲である以上、好みの差と要件の充足度の差が混ざる。

本ツールの目的は「指定した要件がそのまま音になること」なので、
**判定は「要件表の各項目が音として現れているか」に還元する**。
要件表は既にあるので、これは項目ごとに○×を付けられる。

## 5. 判定規則

1. 条件ごとに4曲の**平均点**を出す
2. 平均の差が **1.5点以上** → その条件が優位
3. 差が 1.5点未満 → **同等**と判断する

### 同等だった場合の既定

**条件B（詳細プロンプト＋オフ）を既定とする。**

理由: 入力と出力の対応が追跡でき、同じ入力から同じ結果が得られる。
本ツールは「判断の根拠が追跡できる形で進める」ことを目的としているため、
結果が同等なら再現性の高いほうを採る。

### 条件Aが優位だった場合

Suno 側の書き換えのほうが有効ということになり、次の見直しが必要になる。

- R-17（出力する粒度）の既定を「基本のみ」に寄せるか検討
- B-05v1（バリエーションがオフ以外のときの書き方）の指示を強化
- UI でバリエーション「標準」を推奨する表示を出すか検討

### 条件Bが優位だった場合

- UI でバリエーション「オフ」を推奨する表示を出すか検討
- B-05v0 の検証（現時点で未実施）を優先する

## 8. 注意

- **16項目を厳密に採点しようとしすぎないこと。** 迷ったら △ でよい。
  必要なのは条件間の差であって、絶対値の正確さではない
- C-06（和笛が主旋律）と C-08（言葉のない合唱）は、
  依頼文で「保持」「拡張可」を分けた項目なので、差が出やすい箇所として注目する
- 4曲すべてが低得点だった場合、**プロンプトではなく要件そのものが Suno にとって
  無理筋**という可能性がある（和楽器＋大編成オーケストラ＋合唱＋速いテンポの同居）。
  その場合は H-07 の判定を保留し、要件を減らした別ケースで再試行する

## 9. 判定（2026-09-16）

### 9-1. 結果

| 条件 | 平均 |
|---|---|
| A（基本＋標準） | 15.5 / 16 |
| B（詳細＋オフ） | 15.5 / 16 |
| 差 | **0.0** |

全16項目・全8曲で採点が完全に一致した。C-06（和笛が主旋律）のみ全曲 △で、
これは音が出ていないのではなく、**楽器の音色を聴き分けられなかったための判定不能**（記入者備考）。
両条件に等しくかかるため、条件間の差には影響しない。

### 9-2. H-07 の判定

差が 1.5 点未満のため **同等**。
§5 の規則に従い、**既定は条件B（詳細プロンプト＋バリエーションオフ）**とする。
入力と出力の対応が追跡でき、同じ入力から同じ結果が得られるため。

条件 C・D は実施しない（§3 の規定により、A と B に差が出た場合のみ必要）。

### 9-3. この結果の限界（重要）

**両条件とも満点近くなので、このテストには差を検出する感度がなかった（天井効果）。**
正確には「両者は同等」ではなく、
**「この要件セットではどちらも要件をほぼ満たし、差を検出できなかった」**が正しい。

将来差が出得るのは次のような場合と考えられる。これらに該当するケースで再試行すれば
判定が変わる可能性がある。

- 要素数がさらに多い（短い入力では拾いきれない）
- 互いに衝突しやすい要素を含む
- 一般的でない組み合わせ（Suno が補えない）

今回の要件は「和風オーケストラのボス戦 BGM」という、Suno が得意な類型だった可能性が高い。

### 9-4. 副産物（本題より重要）

書き換え後スタイル文から、当初の目的とは別の発見があった。詳細は
`../research/suno-profile.md`「生成後のスタイル文の観察」に記録した。

| 発見 | 意味 |
|---|---|
| **除外欄はスタイル文末尾の `-語` として統合される** | F-03（No を付けない）の直接の裏付け。Suno 自身がマイナス記号で否定を表している |
| **4曲すべてが `Orchestral` で始まった** | H-01（先頭の要素は書き換えられにくい）の支持材料。RP-06「重要な要素を先頭に」の根拠が強まった |
| 様式名が具体的な楽器名に吸収された | 音としての和風さは保たれており実害はない。様式名の保持を強める必要はない |
| 除外の4要素は全曲で混入なし | 除外欄は実際に効いている |

### 9-5. 判定方法の改善点

**C-06（和笛が主旋律を担う）は聴いて判定できなかった。**
同様のチェックリストを今後使う場合は、楽器の同定を要する項目を
「参考」に降格するか、「笛系の音が旋律を担っているか」のように
**楽器の特定を要求しない表現**に改める。
