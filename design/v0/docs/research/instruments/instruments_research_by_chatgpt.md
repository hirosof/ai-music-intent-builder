# 楽器・音源の系統別一覧

> 最終更新: 2026-09-17
>
> この一覧は、実在するアコースティック／電気・電子楽器に加え、DTM・DAW・VST/AU/AAX等で扱われる仮想楽器、シンセサイザー、サンプラー、ドラム音源、効果音系音源まで含めて整理したものです。
>
> 「楽器学上の厳密な分類」よりも、**DTMで音源やプリセットを探しやすい実用的な分類**を優先しています。そのため、一部の楽器は複数カテゴリに属し得ます。

# 補足：分類上の注意

- **サクソフォン**は材質が金属ですが、発音原理上は木管楽器として扱われます。
- **ピアノ**は弦をハンマーで叩くため、楽器学的には弦鳴楽器として扱う分類もありますが、DTMでは通常「Piano / Keyboard」として独立します。
- **チェレスタ**は鍵盤楽器ですが、発音体は金属板であり、DTMでは「Keys」「Chromatic Percussion」のどちらにも現れます。
- **ハープ、ギター、琴、三味線**などはすべて撥弦楽器ですが、DTMでは用途や音色の違いから別カテゴリに分けられることが一般的です。
- **ボイス／合唱**は厳密には「楽器」ではありませんが、音源ライブラリでは独立カテゴリとして非常に一般的です。
- **Synth Lead / Pad / Bass / Pluck / FX**などは物理的な楽器名ではなく、音色の役割や性質に基づく分類です。
- **サンプラー**はそれ自体が特定の音色を持つのではなく、読み込むサンプルによって任意の楽器や効果音を再現できます。
- **フィジカルモデリング音源**では、実在楽器を録音せずに、その振動や共鳴の仕組みを計算で模倣する場合があります。
- 同じVST音源でも「サンプル＋シンセ」「物理モデリング＋サンプル」など複数方式を組み合わせることがあります。
