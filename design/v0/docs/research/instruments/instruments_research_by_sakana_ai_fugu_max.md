## 1. 楽器の分類法

楽器の分け方は、地域や目的によって複数あります。同じ楽器が複数の枠に入ることも珍しくありません（例: ピアノは打弦楽器でもあり鍵盤楽器でもある）。

### 1.1 ホルンボステル＝ザックス分類（学問的な基本）

1914年にエーリヒ・M・フォン・ホルンボステルとクルト・ザックスが提案した、発音原理による分類です。民族音楽学・楽器学で最も広く使われ、後に電鳴楽器が加わって5分類になりました。

| 番号 | 分類 | 発音源 | 身近な例 |
|------|------|--------|----------|
| 1 | 体鳴楽器（イディオフォン） | 楽器本体の振動 | シンバル、木琴、トライアングル、カリンバ |
| 2 | 膜鳴楽器（メンブラノフォン） | 張った膜の振動 | 太鼓、ティンパニ、タンバリン |
| 3 | 弦鳴楽器（コードフォン） | 張った弦の振動 | ヴァイオリン、ギター、ピアノ、ハープ |
| 4 | 気鳴楽器（エアロフォン） | 空気の振動 | フルート、トランペット、オルガン、アコーディオン |
| 5 | 電鳴楽器（エレクトロフォン） | 電気・電子回路 | シンセサイザー、テルミン、電子ピアノ |

博物館や研究では、この番号をデューイ十進分類のように細かく伸ばします（例: ピアノは弦鳴楽器の打弦＋鍵盤）。

### 1.2 西洋音楽での慣用分類

オーケストラや吹奏楽では、演奏現場の便宜で次のように分けます。基準が一貫していない（材質・奏法・形態が混在する）点が学問的分類との違いです。

- **弦楽器** … ヴァイオリン属など
- **木管楽器** … リードの有無で細分（フルートは金属製でも木管）
- **金管楽器** … 唇の振動（リップリード）
- **打楽器** … 体鳴・膜鳴・一部の気鳴（ホイッスル等）をまとめる
- **鍵盤楽器** … 操作装置による横断カテゴリ
- **電気・電子楽器** … 増幅または電子発音

### 1.3 その他の伝統的分類

- **中国の八音** … 金・石・糸・竹・匏（ひょうたん）・土・革・木
- **日本の雅楽・邦楽** … 弾き物（弦）・吹き物（管）・打ち物（打）
- **インド** … 弦・管・皮製打楽器・金属製打楽器

本資料では、ホルンボステル＝ザックスを骨格にし、現場で使いやすい西洋の慣用名と地域系統を併記します。

## 2. 弦鳴楽器（コードフォン）

張力をかけた弦の振動が発音源です。奏法で大きく3系統に分かれます。

### 2.1 擦弦楽器（弓で擦る）

弦を弓の毛で擦り、持続音を出します。

#### ヴァイオリン属（西洋の主流）

ルネサンス〜バロック期のヴィオール属から発展し、現代オーケストラの中核です。

| 楽器 | 調弦の目安 | 役割 |
|------|------------|------|
| ヴァイオリン | G-D-A-E | 高音の主旋律。第1・第2に分かれる |
| ヴィオラ | C-G-D-A | 中音の内声 |
| チェロ | C-G-D-A（1オクターブ下） | 低音旋律と和声 |
| コントラバス | E-A-D-G（主に4度調弦） | 最低音の土台 |

派生・関連:

- **フィドル** … ケルト・北米などの民俗ヴァイオリン
- **古楽器** … バロック・ヴァイオリン、ヴィオラ・ダモーレ
- **ヴィオール属** … ヴィオラ・ダ・ガンバ、ヴィオラ・ダ・ブラッチョ など（フレット付き、平らな裏板）

#### 東アジアの擦弦

- **胡琴類（中国）** … 二胡、高胡、中胡、京胡、板胡、墜胡 など。蛇皮または木製の共鳴胴、2弦が基本
- **胡弓（日本）** … 三味線に弓を当てた擦弦。内地胡弓、沖縄の胡弓、四絃・五絃の改良型
- **奚琴・ヘグム（海琴）** … 朝鮮半島。二胡に近い2弦擦弦
- **アジェン（牙箏）** … 朝鮮の擦弦ツィター（箏を弓で擦る）

#### 南アジア・中東・他

- **サーランギ** … 北インド。多数の共鳴弦、声に近い timbre
- **エスラジ** … ベンガル。シタールに似た棹を弓で弾く
- **カマンチェ（カマンチャ）** … イラン・コーカサスのスパイクフィドル
- **ラバーブ（擦弦型）** … 中東〜中央アジアに多様な擦弦リュート
- **モリンホール（馬頭琴）** … モンゴル。馬の頭の装飾、2弦
- **ニッケルハルパ** … スウェーデン。鍵盤付き擦弦
- **ハーディ・ガーディ** … 車輪で弦を擦る、クランク式

### 2.2 撥弦楽器（弾く）

指、爪、ピック、撥などで弦を弾きます。胴の形でリュート型・ツィター型・ハープ型に分かれます。

#### リュート型（棹がある）

**ギター系統**

- クラシックギター（ナイロン弦）
- スチール弦アコースティック（フォーク、ドレッドノート、ジャンボ等）
- フラメンコギター
- ウクレレ（ソプラノ〜バリトン）
- エレキギター → [電気楽器](#7-電気楽器) も参照
- 12弦ギター、レゾナーターギター（ドブロ）、スライド／スチールギター
- ベースギター（アコースティック／エレクトリック）

**マンドリン系統**

- マンドリン、マンドラ、マンドロンチェロ、マンドローネ
- ブズーキ（ギリシャ）、シターン、ブズーキ系のアイリッシュ・ブズーキ

**バンジョー系統**

- 4弦／5弦バンジョー、テナーバンジョー（ジャズ）

**リュート・ウード系統**

- ルネサンス／バロック・リュート、テオルボ、キタローネ
- **ウード** … 中東のフレットレス撥弦。西洋リュートの祖
- **サズ／バーラマ** … トルコ等の長棹リュート
- **タンブール、セタール、タール** … ペルシャ系
- **チャランゴ** … アンデス。小型、アルマジロ胴の伝統型あり
- **クアトロ、トレス、レイキント** … カリブ・ラテンの小型ギター族

**東アジアのリュート**

- **琵琶（中国: ピーパ）** と日本の琵琶（楽琵琶、平家、薩摩、筑前、盲僧）
- **阮咸（ルアン）、月琴、柳琴、三弦**
- **三味線**（細棹・中棹・太棹。長唄、地歌、義太夫、津軽など種目で仕様が違う）
- **三線**（沖縄）、ゴッタン（南九州）、トンコリ（アイヌ）

**インドの撥弦リュート**

- **シタール** … 可動フレット、共鳴弦、ミズラーブ（爪）
- **スルバハール** … 低音シタール
- **サロード** … 金属指板、フレットレス
- **ヴィーナ（ルドラ・ヴィーナ、サラスヴァティー・ヴィーナ）**
- **タンブーラ（タンプーラ）** … ドローン専用

**西アフリカ**

- **コラ** … 21弦前後のハープ・リュート。グリオ（世襲音楽家）の楽器
- **ンゴニ**（ドンソンゴニ、カメレンゴニ 等）

#### ツィター型（棹がなく、胴の上に弦を張る）

- **ツィター、ダルシマー（ハンマード・ダルシマーは打弦）**
- **カンテレ**（フィンランド）、**カンテレ系バルト諸国のコクレ**
- **チター、オートハープ**
- **箏（そう／こと）** … 日本。13弦が基本、17弦、20弦、25弦などの拡張
- **和琴（わごん）** … 日本古来の6弦
- **古筝（グージェン）**、古琴（グーチン）、瑟
- **カヤグム（伽倻琴）、コムンゴ（玄琴）** … 朝鮮
- **カヌーン** … 中東の箱型ツィター
- **サントゥール** … ペルシャ等の打弦ツィター
- **ダン・チャン（ベトナム）、ツェンバルム（ハンガリー）**

#### ハープ型（弦が共鳴体から離れて扇状・平行に張られる）

- コンサートハープ（ペダルハープ）
- レバーハープ、アイリッシュハープ、ケルトハープ
- パラグアイハープ などのラテン系
- 古代・復元: 箜篌（くご）、ライアー、キタラ

### 2.3 打弦楽器（叩く）

- **ピアノ** … ハンマーで弦を打つ。グランド／アップライト。古楽器としてフォルテピアノ
- **クラヴィコード** … タンジェント（金属片）が弦に触れて発音
- **ヤンチン（揚琴）**、ハンマード・ダルシマー、ツィンバロン
- **サントゥール**（ペルシャ）

※チェンバロは鍵盤でプレクトラム（爪）が弦を弾くため、分類上は撥弦です。

## 3. 気鳴楽器（エアロフォン）

空気を振動させて音を出します。管の有無で「吹奏楽器」と「自由気鳴楽器」に分かれます。

### 3.1 無簧（エアリード）＝フルート族

息をエッジに当てて空気を割ります。いわゆる木管の一部ですが、材質は木でも金属でもプラスチックでも構いません。

**横笛**

- コンサートフルート、ピッコロ、アルトフルート、バスフルート
- 篠笛、能管、龍笛、神楽笛、高麗笛
- 中国の笛子（膜孔＝膜鳴的噪音を持つ点が特徴）、梆笛、曲笛
- アイリッシュ・フルート、フィフ

**縦笛（ダクトあり）**

- リコーダー（ソプラニーノ〜サブコントラバスまでのファミリー）
- ティン・ホイッスル、ロー・ホイッスル
- オカリナ、土笛、石笛
- 鍵盤ハーモニカ（ピアニカ等）はフリーリードだが、学校教育では管楽器扱いされることも多い

**縦笛（ダクトなし＝エンドブロー）**

- **尺八**、一節切、天吹
- 簫（しょう／シャオ）、洞簫
- **バンスリー**（インドの横／縦の竹笛。代表は横笛型）
- **ネイ（ナイ）** … 中東のエンドブロー竹笛
- パンパイプ（サンポーニャ、ナイ、排簫）
- 尺八系の stateless 民族縦笛（例: クェーナ＝アンデス）

### 3.2 単簧（シングルリード）

1枚のリードがマウスピースに当たって振動します。

- **クラリネット族** … 変ロ管、A管、Es管（エスクラリネット）、アルト、バセットホルン、バスクラリネット、コントラバスクラリネット
- **サクソフォーン族** … ソプラニーノ、ソプラノ、アルト、テナー、バリトン、バス、コントラバス 等（円錐管、金属製だが木管）
- チャルメラ、タローガト
- 民族: 中国の管子に近い単簧、チャルメラ系の東南アジア笛 など

### 3.3 複簧（ダブルリード）

2枚のリードを合わせて振動させます。

- **オーボエ**、オーボエ・ダモーレ、イングリッシュホルン（コーラングレ）、バスオーボエ、ヘッケルフォーン
- **ファゴット、コントラファゴット**
- 古楽器: ショーム、ドゥルシアン、クルムホルン、ラックット
- **篳篥**（日本雅楽。短い竹管、大きなリード、独特の塩梅＝ピッチ操作）
- **スオーナ**（中国）、タイのピー、韓国のピリ
- **ズルナ、ミャー、ドゥドゥク**（アルメニア。アプリコット管の複簧、持続ドローンと相性が良い）

### 3.4 唇簧（リップリード）＝金管

奏者の唇をマウスピースで振動させます。材質が真鍮である必要はなく、発音原理で金管に分類します。

**円筒管寄り（トロンバ系）**

- トランペット（B♭、C、ピッコロ、バス）
- トロンボーン（テナースライド、バス、バルブトロンボーン）
- ナチュラルトランペット、クラリーノ（古楽器）

**円錐管寄り**

- **ホルン（フレンチホルン）**、ワグナーチューバ
- コルネット、フリューゲルホルン
- ビューグル
- **サクソルン族** … アルトホルン、バリトン、ユーフォニアム、チューバ（F、E♭、C、B♭）
- スーザフォン、ヘルリコン（行進用）

**その他**

- セルパン、オフィクレイド（古楽器、チューバの前身的存在）
- **ホルンガイ（法螺貝）** … 唇簧の自然楽器。日本の山伏・祭礼でも使用
- ディジュリドゥ … オーストラリア先住民。唇の振動と循環呼吸、ドローン

### 3.5 自由簧（フリーリード）

リードが枠の中で自由に振動し、必ずしも長い共鳴管を必要としません。

- **アコーディオン、バンドネオン、コンサーティーナ**
- ハーモニカ、鍵盤ハーモニカ
- **笙（しょう）、竽（う）** … 日本雅楽。和音が出せる
- **笙（中国のション）、ルシェン、フールースー（葫蘆絲）、バゥ（巴烏）**
- **サウン（ミャンマーの弓形ハープは弦）、ケン（タイ・ラオスのフリーリード口琴オルガン）**
- リードオルガン、ハーモニウム

### 3.6 多管・袋管

- **パイプオルガン** … 多数のパイプ（フルー管＝エアリード、リード管＝有簧）を鍵盤で選択
- **バグパイプ類** … グレート・ハイランド、イリアン・パイプス、ガイタ、コルヌミューズ、ビニウ 等。ドローン管＋チャンター

## 4. 体鳴楽器（イディオフォン）

膜や弦ではなく、固体そのものが鳴ります。打楽器の大半がここに入ります。

### 4.1 打ち合わせて鳴らす

- シンバル（クラッシュ、サスペンデッド、ハイハット）
- カスタネット、クラベス、拍子木、笏拍子
- トライアングル
- フィンガーシンバル（ジル）、撞木と鉦の一部

### 4.2 叩いて鳴らす（単体）

**金属**

- ゴング、タムタム、銅鑼
- ベル、ハンドベル、カウベル、アゴゴ
- チューブラーベル（チャイム）
- 鉄琴（グロッケンシュピール）、ヴィブラフォン、クロマティック・ベル
- スチールパン（スティールドラム）
- 日本の鉦、鈴、磬、半鐘、鰐口

**木**

- ウッドブロック、テンプルブロック
- スレイベル、 kastagnet 以外の木製打
- 木魚
- カホン（箱自体が鳴る体鳴。ペルー発祥）
- スリットドラム（ログドラム、 duala、木鼓）

**鍵盤打楽器（音高が明確）**

| 楽器 | 発音体 | 備考 |
|------|--------|------|
| シロフォン | 木条 | 高音、硬質 |
| マリンバ | 木条＋共鳴管 | 低音まで広く、温暖 |
| ヴィブラフォン | 金属条＋共振管＋ビブラート機構 | ジャズ定番 |
| グロッケン | 金属条 | オーケストラの高音点描 |
| チェレスタ | 金属板を鍵盤ハンマーで叩く | チャイコフスキー『くるみ割り人形』など |
| リトフォン | 石 | 石琴、編磬 |
| アンクルン | 竹 | インドネシア。振って鳴らす竹ラトルの音階セット |

### 4.3 弾いて鳴らす（ラメラフォン）

細い舌状の板を弾きます。

- **カリンバ、ムビラ（ンビラ）、サンサ** … アフリカ起源のサムピアノ
- **口琴（こうきん）、ムックリ**（アイヌ）、Jew's harp
- オルゴール（ディスク／シリンダーが櫛歯を弾く）

### 4.4 擦って鳴らす

- ギロ、レコレコ、ウォッシュボード
- グラスハーモニカ（回転するガラスを濡れた指で擦る）
- ミュージカルソー（のこぎり）

### 4.5 振って鳴らす

- マラカス、シェイカー、カバサ
- タンバリンのジングル（膜があれば複合）
- 鳴子、振鈴、 rattles 全般

## 5. 膜鳴楽器（メンブラノフォン）

張った膜を叩く・擦る・歌うことで鳴らします。いわゆる太鼓です。

### 5.1 西洋オーケストラ・バンド

- **ティンパニ**（音高可変の釜太鼓）
- スネアドラム、バスドラム、トムトム
- テナードラム、フィールドドラム
- タンバリン（膜＋ジングルで体鳴との複合）
- ボンゴ、コンガ、ティンバレス → ラテンは [10.6](#106-ラテンアメリカ) も参照

### 5.2 ドラムセット（複合）

バスドラム、スネア、タム、ハイハット、シンバル類を一人で演奏する編成。ロック、ジャズ、ポップスのリズムの中核。電子ドラム（パッド＋音源）は電鳴とのハイブリッドです。

### 5.3 日本の太鼓・鼓

- 長胴太鼓、桶胴太鼓、締太鼓
- 大太鼓、宮太鼓、祭太鼓
- 小鼓、大鼓、太鼓（能・歌舞伎）
- 団扇太鼓、枠太鼓

### 5.4 世界の代表的な太鼓

- **ジャンベ（ジェンベ）** … 西アフリカの杯型太鼓
- ドゥンドゥン、サバール、トーキングドラム（ Tribes の可変音高太鼓）
- **タブラ** … 北インドの対太鼓（ダヤ／バヤ）
- ムRIDANGAM、パカーワジ … 南インド・ヒンドゥスターニーの両面太鼓
- **ダルブッカ（ダラブッカ、トンバク）** … 中東の goblet drum
- ダフ、リク … フレームドラム
- 韓国のチャンゴ（杖鼓、砂時計型）、クァンガリ（ただしクァンガリは体鳴の銅鑼）
- 中国の堂鼓、排鼓、大鼓
- ラテン: コンガ、ボンゴ、ティンバレス、パンデイロ、スルド、レペンキ、クイーカ（膜を擦る）

## 6. 鍵盤楽器

鍵盤は発音原理ではなく**操作機構**です。中身は弦・気・体・電のどれかです。

| 楽器 | 発音原理 | 特徴 |
|------|----------|------|
| ピアノ | 打弦 | 強弱が付けられる。88鍵が標準 |
| フォルテピアノ | 打弦 | 18〜19世紀。現代ピアノより軽い |
| チェンバロ（ハープシコード） | 撥弦 | 爪で弾く。強弱は限定的 |
| スピネット、ヴァージナル | 撥弦 | 小型チェンバロ族 |
| クラヴィコード | 打弦に近い接触 | 小さな音、ビブラート（ベーブンク）が可能 |
| パイプオルガン | 気鳴 | 持続音。複数鍵盤＋足鍵盤 |
| リードオルガン、ハーモニウム | 自由簧 | 学校・家庭・インド音楽の伴奏 |
| チェレスタ | 体鳴（金属） | 鍵盤付き鉄琴に近い |
| アコーディオン、バンドネオン | 自由簧 | 可搬の鍵盤／ボタン鍵盤 |
| 電子ピアノ、シンセ、エレクトーン | 電鳴 | [8](#8-電子楽器とシンセサイザー) へ |

## 7. 電気楽器

**物理的な発音体があり、その振動をピックアップで電気信号に変えて増幅する**楽器です。電子回路で波形をゼロから作る電子楽器とは区別します。

- **エレクトリックギター** … ソリッド、セミアコ、フルアコ。シングルコイル／ハムバッカー
- **エレクトリックベース** … プレシジョン、ジャズ、フレットレス、多弦（5〜7弦等）
- エレクトリック・ヴァイオリン、チェロ、マンドリン、シタール 等
- **エレクトリックピアノ（電気式）** … Rhodes（音叉をハンマー）、Wurlitzer（リードをハンマー）、Clavinet（弦を弾いてピックアップ）
- エレクトリックハープ、スチールギター（ペダルスチール）
- ピックアップ付きアコースティック（エレアコ）は「電気増幅された弦鳴」

アンプ、エフェクター、スピーカーまで含めて音色が完成する点が、生楽器との大きな違いです。

## 8. 電子楽器とシンセサイザー

発音そのものが電気・電子回路、またはデジタル演算によるものです。

### 8.1 初期の電子楽器

- **テルミン** … アンテナ周囲の静電容量で音程・音量を制御。非接触
- **オンド・マルトノ** … 鍵盤＋リボン。メシアン作品などで有名
- トラウトニウム、テルハルモニウム（巨大な初期電気オルガン）

### 8.2 シンセサイザーの合成方式

ソフト音源（VST）も、中身はこのどれか、または組み合わせ（ハイブリッド）です。

| 方式 | 原理 | 得意な音 | 代表的なイメージ |
|------|------|----------|------------------|
| 減算合成（サブトラクティブ） | 倍音の多い波形からフィルターで削る | アナログ的なパッド、バス、リード | Moog、多くのアナログ／ヴァーチャルアナログ |
| 加算合成（アディティブ） | 正弦波を重ねる | オルガン、ベル、精密な倍音制御 | ハモンド的ドローバー、Fairlightの一部 |
| FM（周波数変調） | オペレータ同士で周波数を変調 | ベル、エレクトリックピアノ、金属質、鋭いアタック | DX7、FM8 |
| ウェーブテーブル | 1周期波形のテーブルを横断して音色変化 | 現代的なパッド、ベース、動きのある音色 | PPG Wave、Serum 系 |
| PCM／サンプリング | 録音波形を再生・加工 | 生楽器のリアル再現 | 電子ピアノ、ROMpler、サンプラー |
| フィジカルモデリング | 弦・管・膜の物理を数式で模擬 | 管楽器、撥弦、擦弦の奏法変化 | SWAM、MODO BASS 等 |
| グラニュラー | 波形を粒（グレイン）に分割して再配置 | テクスチャ、アンビエント、 timbre の融解 | 一部の Omnisphere、専用グラニュラーシンセ |
| ベクトル／ウェーブシーケンス | 複数波形を時間的にミックス | 動き続けるパッド | Prophet VS、Wavestation |
| 位相歪み（PD） | 読み出し位相を歪ませて倍音を変える | カシオ系のデジタル | CZシリーズ |
| ハイブリッド | 上記の併用 | 万能 | 現代のソフトシンセの多数 |

### 8.3 電子ピアノ・電子オルガン・その他

- 電子ピアノ（サンプリングまたはモデリング）
- 電子オルガン、エレクトーン
- デジタルアコーディオン
- ヴォコーダー、トークボックス
- リズムマシン、グルーヴボックス
- 電子ドラム

## 9. DTMの仮想楽器（VST等）

DAW（Cubase、Studio One、Ableton Live、Logic、FL Studio 等）上で動くソフトウェア楽器です。物理的な胴や管はありませんが、**再現対象の系統**と**合成方式の系統**の両方で分類できます。

### 9.1 プラグインの規格

| 規格 | 主な環境 |
|------|----------|
| VST / VST3 | Windows 中心、多くのDAW。現在の事実上の標準 |
| AU（Audio Units） | macOS、Logic 等 |
| AAX | Pro Tools |
| CLAP | 比較的新しい開放的規格 |
| スタンドアローン | DAWなしで単体起動 |
| サンプラー用ライブラリ | Kontakt、UVI Falcon、SFZ、sforzando 等の「器」に読み込む |

VSTi は VST 形式のインストゥルメント（音源）を指す通称です。エフェクトプラグイン（VST）とは区別します。

### 9.2 用途（再現対象）による分類

DTMの現場では、合成方式より「何の音が出るか」で選ぶことが多いです。

#### 鍵盤・ピアノ系

- グランド／アップライトのサンプリングピアノ
- エレピ（Rhodes、Wurlitzer、DX系）
- チェンバロ、オルガン（パイプ、ドローバー、教会）
- 例の系統: Ivory、Pianoteq（モデリング）、Keyscape、各種無料ピアノ（Salamander 等）

#### ドラム・パーカッション系

- アコースティックキット（多マイク、MIDIグルーヴ付き）
- 電子ドラム／ドラムマシン（808、909 系）
- ラテン、民族、シネマティック打楽器
- 例の系統: Superior Drummer、BFD、Addictive Drums、Battery、TR系エミュ

#### ベース系

- フィンガー／ピック／スラップのエレキベース
- アップライト（ウッド）ベース
- シンセベース専用
- モデリング例: MODO BASS のようなフィジカルモデリング

#### ギター系

- アコギ、エレキ、ナイロン、12弦
- 奏法（ストローク、アルペジオ、スライド、ミュート）を自動・半自動で再現するタイプ
- アンプシミュ（Guitar Rig 等）と組み合わせて完成する
- 例の系統: Ample Guitar、MusicLab、UJAM Virtual Guitarist、Prominy

#### オーケストラ・シネマティック系

- セクション（Vn/Va/Vc/Cb のアンサンブル）
- ソロ楽器
- ブラス、ウッドウィンド、ハープ、合唱
- トレーラー系の巨大打楽器、 riser、hit
- 例の系統: Spitfire、Vienna、EastWest、Orchestral Tools、BBC SO 系

#### 民族・ワールド系

- 和楽器、中国楽器、インド、アフリカ、中東、ケルト などをサンプリングまたはモデリング
- 総合ワールドライブラリ（例: UVI World Suite 系）

#### ボーカル・コーラス系

- 歌声合成（Vocaloid、Synthesizer V、CeVIO 等 ※規格はVSTとは限らない）
- 合唱（男声／女声／少年）のサンプリング
- ボーカルテクスチャ、ボイスデザイン

#### シンセ・デザイン系

- バーチャルアナログ
- ウェーブテーブル（現代EDMの中心の一つ）
- FM、モジュラー／セミモジュラー
- テクスチャ・アンビエント専用

#### 総合音源・ROMpler

- 多数カテゴリを1つに収録したワークステーション型
- 例の系統: Native Instruments KOMPLETE（Kontakt＋複数シンセ＋音源）、DAW付属音源

### 9.3 技術方式による分類（ソフト音源の中身）

1. **サンプラー／ROMpler**  
   録音済み波形を再生。生楽器のリアリティに強い。容量は数十GB〜数百GBになることもある。ラウンドロビン（同じ音の録音を複数持ち、連打の機械感を減らす）、ベロシティレイヤー、リリースサンプルが品質の鍵。

2. **ヴァーチャルアナログ**  
   アナログ減算合成の回路をデジタルで模擬。CPU負荷は比較的低め。ベース、リード、パッド。

3. **ウェーブテーブルシンセ**  
   1周期波形をテーブルとして持ち、位置を動かして音色変化。EDM、ポップスの「今っぽい」音。

4. **FM／オペレータ型**  
   ベル、ベース、複雑な倍音。パラメータが抽象的で学習コストがある。

5. **フィジカルモデリング**  
   弦の材質、ピッキング位置、管長、息圧などを数値化。容量が小さく、同一音の連打でも変化が出やすい。管楽器・撥弦に強い。

6. **グラニュラー／スペクトル**  
   既存の音を粒子化・再合成。効果音、アンビエント、声の加工。

7. **モジュラー**  
   オシレータ、フィルタ、LFO、シーケンサをパッチング。音作りの自由度が最大。ハードウェアEurorackのソフト版も含む。

### 9.4 仮想楽器ならではの系統

実在楽器の模倣を超えたカテゴリです。

- **ドラムマシン音源** … 電子的なキック、スネア、ハットの文化そのもの（ヒップホップ、テクノ）
- **チップチューン／レトロゲーム音源** … PSG、FM音源チップの模擬
- **シネマティックSFX楽器** … 誰も現場で「演奏」しないヒット、ブラス・スタブ、逆再生、ドローン
- **MIDIギター／フレーズ楽器** … コードを押さえるとパターンが鳴る（UJAM 型）
- **AI／ニューラル音源** … 学習モデルで音色や演奏を生成する新しい系統（発展途上）

### 9.5 生楽器との対応関係（DTMでの使い方）

| 実在の系統 | 仮想化の典型 | 注意点 |
|------------|--------------|--------|
| ピアノ | 大容量サンプリング or モデリング | ペダル、共鳴、ハンマーノイズの再現度 |
| 弦楽 | レガートパッチ、複数 dynamik | ソロはモデリングや詳細サンプリングが有利 |
| 管楽器 | レガート＋キースイッチ、または物理モデル | 息のダイナミクスが不自然になりやすい |
| ギター | ストロークエンジン＋ノイズサンプル | コードボイシングと弦選択が課題 |
| ドラム | 多マイクキット＋MIDIグルーヴ | 生録音とのレイヤーが定番 |
| 民族楽器 | 専用ライブラリ | 調律（平均律以外）と奏法の知識が必要 |
| シンセ | ソフトシンセそのもの | 実機の回路ノイズや個体差をどこまで入れるか |

## 10. 世界の民族楽器

西洋クラシックとポピュラーの「標準編成」に入らない、地域に根ざした系統です。国境をまたいで伝播しているものも多いため、代表的な文化圏で示します。

### 10.1 日本（和楽器）

日本では古く「糸竹（いとたけ）」とも呼びました。大陸伝来を日本化したものが大半で、和琴・神楽笛・土笛などは日本古来とされます。

**弦（弾き物）**

- 箏、十七絃箏、和琴、一絃琴、二絃琴、大正琴
- 三味線（細棹・中棹・太棹）、三線、ゴッタン
- 琵琶（楽、平家、薩摩、筑前、盲僧）
- 胡弓、トンコリ（アイヌ）

**管（吹き物）**

- 横笛: 篠笛、能管、龍笛、神楽笛、高麗笛
- 尺八、一節切
- 篳篥、大篳篥
- 笙、竽
- 法螺貝

**打（打ち物）**

- 各種和太鼓、小鼓、大鼓
- 鉦、鈴、拍子木、笏拍子、鳴子
- ムックリ（アイヌの口琴）

特徴として、西洋近代楽器より音量が小さい室内系が多い一方、祭礼の太鼓・笛は非常に大きい、という二極があります。三味線の「さわり」のように、噪音（倍音以外の成分）を美とする点がしばしば指摘されます。

### 10.2 東アジア

**中国（伝統的には八音で分類）**

- 擦弦: 二胡、高胡、京胡、板胡
- 撥弦: 琵琶、古筝、古琴、阮、三弦、柳琴、揚琴
- 管: 笛子、簫、笙、嗩吶（スオーナ）、管子、巴烏、葫蘆絲、蘆笙
- 打: 鑼、鈸、堂鼓、編鐘、編磬

**朝鮮半島**

- カヤグム、コムンゴ、ヘグム、アジェン
- テグム（대금）、ピリ、タンソ、センファン（笙の仲間）
- チャンゴ、クァンガリ、チン（銅鑼）

### 10.3 南アジア（インド亜大陸）

- 撥弦: シタール、サロード、ヴィーナ、タンブーラ
- 擦弦: サーランギ、エスラジ
- 管: バンスリー、シェナイ、ナルシンガ
- 打: タブラ、ムリダンガム、パカーワジ、ガンジラ、マンジラ
- 自由簧: ハルモニウム（インド音楽に定着した欧州起源）

古典音楽ではラーガ（旋律規範）とターラ（リズム周期）に合わせて、ドローン（タンブーラ）＋主奏＋太鼓、という編成が典型です。

### 10.4 東南アジア

- **ガムラン（インドネシア）** … 青銅の鍵盤打楽器、ゴング、ドラムの合奏体系。楽器単体というよりオーケストラそのものが「楽器系統」
- アンクルン（竹）
- ラナート（タイの木琴）、ケーン（フリーリード）、サウンガウ（ビルマの弓形ハープ）
- ダン・バウ（ベトナムの一弦）、ダン・チャン、ダン・グエット

### 10.5 中東・北アフリカ・中央アジア

- 撥弦: ウード、サズ、タール、セタール、カヌーン

- 管: ネイ、ズルナ、ドゥドゥク、アルグール

### 10.6 アフリカ（サハラ以南）

打楽器の多様性で知られますが、弦・ラメラも豊かです。

- 膜鳴: ジャンベ、ドゥンドゥン、トーキングドラム、サバール

### 10.7 ラテンアメリカ

スペイン・ポルトガル、先住民、アフリカ系の融合です。

- 打: コンガ、ボンゴ、ティンバレス、カホン、パンデイロ、スルド、アゴゴ、クラベス、ギロ、マラカス、シェケレ

- 蛇腹: バンドネオン（タンゴ）、アコーディオン（フォルクローレ、ノルテーニョ）
- カリブ: スチールパン、レゲエ／キューバの各種打

### 10.8 ヨーロッパの民俗楽器

クラシックの標準から外れた地域楽器です。

- フィドル、ハーディ・ガーディ、ニッケルハルパ
- バグパイプ各種
- アコーディオン、バンドネオン（アルゼンチンで開花したが起源はドイツ）
- カンテレ、ツィター、ダルシマー
- バラライカ、ドムラ（ロシア）
- ブズーキ（ギリシャ）
- アイリッシュ・ハープ、ティン・ホイッスル、ボードラン（フレームドラム）

### 10.9 オセアニア

- ディジュリドゥ

## 11. 特殊・実験的な楽器

既存の5分類の境界をまたぐ、または20世紀以降に意図的に作られたものです。

- **ガラス** … グラスハーモニカ、クリスタル・バシェ
- **水** … ハイドラフォン、水鉢

## 付録A. オーケストラ編成との対応

標準的な交響楽団は、弦5部＋木管＋金管＋打、にハープや鍵盤が加わります。木管の本数で「2管編成」「3管編成」などと呼びます。

| グループ | 標準的なメンバー |
|----------|------------------|
| 弦 | 第1Vn、第2Vn、Va、Vc、Cb（＋ハープ） |
| 木管 | Fl, Ob, Cl, Fg と各派生（Picc, Eh, Bcl, Cfg） |
| 金管 | Hn, Tp, Trb, Tu |
| 打 | Timp 必須、他は曲による |
| 編入 | ピアノ、チェレスタ、オルガン、サクソフォン、合唱 等 |

吹奏楽は弦の代わりにクラリネット族・サクソフォン族を厚くし、金管と打を強化した編成です。
