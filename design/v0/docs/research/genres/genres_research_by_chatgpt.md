# 音楽ジャンル分類一覧

音楽ジャンルは厳密な階層構造が決まっているわけではなく、同じジャンルが複数系統にまたがることもあります。AllMusicも「Genre」を広い分類、「Style」をより細かい下位分類として扱っています。またMusicBrainzではジャンル自体を主観的なタグとして扱っており、非常に多数の細分類が存在します。

今回は**AI作曲時に「どんな音楽を作るか」を指定する用途でも使いやすい分類**として整理しました。したがって、音楽学的な系譜より「音として何系なのか」が分かりやすいことを優先しています。AllMusicの大分類やMusicBrainzのジャンル一覧も参考にしています。

## 全体像としてまとめると

今回の分類を「大系統」だけ抜き出すと、だいたい次のようになります。

```text
POP
├─ 地域系POP
└─ 日本系POP

Rock
Metal
Punk / Hardcore

Electronic / Dance
├─ House
├─ Techno
├─ Trance

├─ Breakbeat
└─ Garage

R&B / Soul
Funk

Blues

Folk / Acoustic

Reggae
Caribbean

Comedy / Novelty
Children's
Holiday / Seasonal
```

重要なのは、**これらは排他的な分類ではない**という点です。たとえば、

```text
Symphonic Metal
= Metal + Classical / Orchestral

Electropop
= Pop + Electronic

Jazz Rap
= Jazz + Hip-Hop

Folk Metal
= Folk + Metal

Cinematic Dubstep
= Cinematic + Dubstep

J-POP × Rock
= J-POP + Pop Rock / Alternative Rock など
```

のように組み合わせられます。

AI作曲、とくにSunoなどでは、この考え方がかなり重要です。単一ジャンルを指定するより、

```text
Symphonic Metal, Cinematic, Japanese traditional instruments, Epic, Female Choir
```

や

```text
J-POP, Progressive Rock, Orchestral, Game Soundtrack, Final Boss Battle
```

のように、**「ジャンル + サブジャンル + 編成 + 雰囲気 + 用途」**を組み合わせたほうが目的の音楽を表現しやすくなります。

なお、MusicBrainzの現行ジャンル一覧だけでも、Acid House、Afrobeat、Dark Ambient、Melodic Techno、Neo City Pop、Psytrance、Trap、Trip Hopなど、ここで挙げたもの以外にも大量の細分類があります。したがって今回の一覧は「全ジャンル完全網羅」ではなく、**主要ジャンルとAI作曲で実用性が高そうなサブジャンルをかなり広くカバーした一覧**と考えるのが適切です。
