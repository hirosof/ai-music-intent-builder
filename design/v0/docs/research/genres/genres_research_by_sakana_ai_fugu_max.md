# 音楽ジャンル系統分類ガイド

音楽のジャンルは、リズム・楽器編成・歌唱法といった**音の特徴**と、発祥地・時代・社会背景といった**文化の文脈**の両方で分類されます。境界はしばしば曖昧で、ひとつの曲が複数のジャンルにまたがることも珍しくありません。本資料は「系統（ルーツと派生）」を軸に、主要なジャンルとその枝分かれを俯瞰するための地図です。

> **読み方のヒント**  
> - 各系統の冒頭に「どこから来たか」を示し、その下に代表的なサブジャンルを並べています。  
> - ジャンル名のあとに、おおよその発祥地・年代と、ごく短い特徴を付けています。  
> - 代表例は入門の手がかりであり、そのジャンルのすべてを代表するものではありません。

## 1. 分類の考え方

音楽ジャンルを分けるとき、よく使われる軸は次のとおりです。

| 軸 | 例 |
| --- | --- |
| 音楽的特徴 | テンポ、リズム、和声、楽器編成、歌唱法、即興の有無 |
| 歴史・系譜 | どのジャンルから派生したか（例：ブルース → ロックンロール） |
| 地域・文化 | 発祥地、言語、宗教、民族、都市文化 |
| 用途・場 | ダンス、礼拝、劇場、映画、クラブ、祭礼 |
| 産業・流通 | チャート向けポップ、インディー、アイドル、アニソンなど |

**注意点**

- ジャンル名は批評家・業界・ファン・配信サービスの便宜上のラベルであり、絶対的な分類ではありません。
- 「J-POP」「洋楽」「アニソン」などは音の構造というより、市場・言語・用途によるラベルです。
- 21世紀以降は融合が加速し、トラップ×ポップ、レゲトン×K-POP、シティポップ×ヴェイパーウェイヴのように、系統を横断する曲が日常的になっています。

## 2. 系統の全体像

ポピュラー音楽の大きな流れを、ごく単純化すると次のようになります。

```text
西洋芸術音楽（クラシック） ── 編曲・和声・形式として各ジャンルへ影響
アフリカ系アメリカ人の音楽
  ├─ ブルース ──┬─ ロックンロール ── ロック／パンク／メタル
  │              ├─ R&B ── ソウル ── ファンク ── ディスコ ── ハウス
  │              └─ ジャズ（並行して発展）
  ├─ ゴスペル ── ソウル／R&B
  └─ ヒップホップ（DJ文化＋ラップ＋サンプリング）

ヨーロッパ／各地の民謡 ── フォーク ── フォークロック、シンガーソングライター
米南部の農村音楽 ── カントリー／ブルーグラス
ジャマイカ ── スカ ── ロックステディ ── レゲエ ── ダンスホール ── レゲトン
ラテンアメリカ ── サンバ／タンゴ／サルサ／クンビア など
電子楽器・クラブ文化 ── テクノ／ハウス／トランス／EDM
```

AllMusic などのデータベースでは、上位カテゴリとして **クラシック、ジャズ、ブルース、カントリー、フォーク、R&B、ラップ、レゲエ、ラテン、エレクトロニック、ポップ／ロック、インターナショナル** などが置かれます。本資料もこの「大きな幹」に沿いつつ、日本の読者向けに邦楽の系統を独立させて整理しています。

## 3. クラシック・芸術音楽

西洋の「芸術音楽（art music）」の系統です。狭義の「クラシック」はおおよそ1750–1820年の古典派を指しますが、一般には中世から現代までの西洋コンサート音楽全体を指して使われます。

### 時代による区分

| ジャンル | おおよその時代 | 特徴 | 代表例 |
| --- | --- | --- | --- |
| 中世音楽 | 〜15世紀頃 | グレゴリオ聖歌、初期の多声音楽 |  Hildegard von Bingen など |
| ルネサンス | 15–16世紀 | ポリフォニー（複数旋律の重ね）が成熟 | パレストリーナ、ジョスカン |
| バロック | 1600–1750年頃 | 通奏低音、対位法、装飾、オペラの成立 | バッハ、ヴィヴァルディ、ヘンデル |
| 古典派 | 1750–1820年頃 | ソナタ形式、均整のとれた構造 | ハイドン、モーツァルト、ベートーヴェン前期 |
| ロマン派 | 19世紀 | 感情・個性・民族性、大編成オーケストラ | ショパン、ブラームス、ワーグナー、チャイコフスキー |
| 近代・現代 | 20世紀〜 | 印象主義、無調、十二音、 distanced 実験 | ドビュッシー、シェーンベルク、ストラヴィンスキー、武満徹 |

### 形態・編成による区分

- **オペラ**（イタリア、17世紀〜）：歌唱・管弦楽・演劇の総合芸術。ヴェルディ、プッチーニなど。
- **オペレッタ**：より軽快・喜劇的な音楽劇。オッフェンバック、レハールなど。
- **交響曲・協奏曲・室内楽**：オーケストラ作品、独奏と管弦楽、少人数アンサンブル。
- **吹奏楽・マーチ**：管打楽器中心。軍楽隊から学校吹奏楽へ広がった。
- **現代音楽（コンテンポラリー）**：シリアル主義、ミニマル、スペクトル、電子音響など。

### 西洋以外の古典・宮廷音楽（参考）

「クラシック」は西洋固有の語ですが、高度に体系化された芸術音楽は各地にあります。

- **インド古典音楽**：ラーガ（旋法）とターラ（リズム）に基づく即興。ヒンドゥスターニー（北）とカルナーティック（南）。
- **アラビア／ペルシャ／トルコの古典音楽**：マカーム（旋法）体系。
- **日本の雅楽**：後述（日本の音楽）。
- **ガムラン**（インドネシア）：金属打楽器アンサンブルの宮廷・儀礼音楽。

## 4. ブルース

**発祥**：米国南部（特にミシシッピ・デルタ）、19世紀末〜20世紀初頭。  
アフリカ系アメリカ人の労働歌・スピリチュアルと、ヨーロッパ系の和声が交わって生まれました。12小節形式とブルーノート（微妙に下げた音）が象徴です。ロック、R&B、ジャズ、ヒップホップの共通の祖先のひとつです。

| サブジャンル | 特徴 |
| --- | --- |
| デルタ・ブルース | アコースティック、生々しい独唱とギター。ロバート・ジョンソンなど |
| シカゴ・ブルース | 電化。アンプとバンド編成。マディ・ウォーターズなど |
| テキサス／ウエストコースト・ブルース | より洗練されたギターワークやスウィング感 |
| カントリー・ブルース | 農村的・個人演奏中心 |
| ジャンプ・ブルース | 1940年代、ダンス向けの軽快なブルース。R&Bの前触れ |
| ブルースロック | 1960年代以降、ロックとの融合。クリーム、ジミ・ヘンドリックスなど |

## 5. ジャズ

**発祥**：米国ニューオーリンズ、20世紀初頭。  
ブルース、ラグタイム、行進曲、アフリカ系のリズムが都市で混ざり、即興とスウィングを核とする音楽になりました。「アメリカのクラシック」と呼ばれることもあります。

| サブジャンル | 年代の目安 | 特徴 |
| --- | --- | --- |
| ディキシーランド／トラディショナル | 1910–20年代 | 集団即興、ブラスとクラリネット |
| スウィング | 1930年代 | ビッグバンド、踊るためのジャズ |
| ビバップ | 1940年代 | 高速・複雑な和声。聴くためのジャズへ |
| クールジャズ | 1950年代 | 抑制された音色、知的な印象 |
| ハードバップ | 1950年代 | ビバップにブルース／ゴスペルの熱を戻す |
| モーダルジャズ | 1950–60年代 | コード進行より旋法（モード）で即興 |
| フリージャズ | 1960年代 | 調性・拍の制約を緩める前衛 |
| ソウルジャズ | 1950–60年代 | グルーヴ重視、オルガントリオなど |
| フュージョン | 1970年代〜 | ロック／ファンクとの融合、電化 |
| ラテンジャズ | 1940年代〜 | キューバ等のリズムとの交差 |
| アシッドジャズ | 1980–90年代 | クラブ向け、ファンク／ヒップホップとの接近 |
| スムースジャズ | 1980年代〜 | 聴きやすさ重視の商業的スタイル |

代表的な名前：ルイ・アームストロング、デューク・エリントン、チャーリー・パーカー、マイルス・デイヴィス、ジョン・コルトレーン、エラ・フィッツジェラルドなど。

## 6. ゴスペル／R&B／ソウル／ファンク

アフリカ系アメリカ人の教会音楽と大衆音楽が、20世紀半ば以降に大きく枝分かれした系統です。感情の強い歌唱、グルーヴ、後のヒップホップやハウスの土台になりました。

### ゴスペル

キリスト教礼拝から生まれた音楽。スピリチュアルを源流とし、コール＆レスポンス、熱のこもった歌唱が特徴。ソウルやR&Bのボーカル表現に直結します。

### R&B（リズム・アンド・ブルース）

1940年代に米国で使われ始めた呼称。当初はアフリカ系アメリカ人向け大衆音楽の総称で、ジャンプ・ブルースやエレクトリック・ブルースを含みました。のちにはソウル、ファンク、コンテンポラリーR&Bへと意味が移ります。

| サブジャンル | 特徴 |
| --- | --- |
| ドゥーワップ | 1950年代、ハーモニー中心のヴォーカルグループ |
| ソウル | 1950–60年代、ゴスペルの熱情＋R&B。アレサ・フランクリン、オーティス・レディングなど |
| モータウン／サザンソウル | デトロイトの洗練 vs 南部の生々しさ |
| ファンク | 1960年代後半〜、ワンコードのグルーヴ、ベースとドラムが主役。ジェームス・ブラウン、Parliament など |
| ディスコ | 1970年代、4つ打ち＋オーケストラ／シンセ。クラブ文化の中心 |
| クワイエットストーム | 遅いテンポのロマンティックなR&B |
| ニュージャックスウィング | 1980年代末、ヒップホップのビート×R&B |
| ネオソウル | 1990年代〜、70年代ソウルの再解釈 |
| コンテンポラリーR&B | 1990年代以降の主流R&B。ビヨンセ、Usher など |

ディスコは後に**ハウス**へ、ファンクのブレイクビーツは**ヒップホップ**へ流れ込みます。

## 7. ロック（パンク・メタルを含む）

**発祥**：1950年代米国のロックンロール。R&Bとカントリーが若者文化の中で交差しました。  
基本編成はエレキギター・ベース・ドラム（＋ボーカル）。反抗性・身体性・バンド文化が核です。派生が非常に多く、ポピュラー音楽最大の「樹」のひとつです。

### 初期と主流の枝

| サブジャンル | 年代の目安 | 特徴 |
| --- | --- | --- |
| ロックンロール | 1950年代 | 強いバックビート、エレキギター。エルビス、チャック・ベリー |
| ロカビリー | 1950年代 | カントリー寄りのロックンロール |
| サーフ | 1960年代初 | トレモロ・ギター、ビーチ文化 |
| ブリティッシュ・インヴェイジョン | 1960年代 | ビートルズ、ストーンズなど英国勢 |
| ガレージロック | 1960年代 | 素人っぽさ、荒々しさ |
| サイケデリックロック | 1960年代後半 | 長尺即興、エフェクト、意識の拡張 |
| ハードロック | 1960年代末〜 | 歪み、大音量、ブルースの重量感。レッド・ツェッペリン、ディープ・パープル |
| プログレッシブロック | 1960年代末〜 | クラシック／ジャズ的な構成と演奏技術。ピンク・フロイド、イエス |
| グラムロック | 1970年代 | 視覚演出、アンドロジナスな美学。ボウイ、T. Rex |
| ソフトロック／AOR | 1970年代 | 洗練された編曲、ラジオ向け |
| フォークロック | 1960年代 | フォークの詞世界＋ロックのバンドサウンド |
| カントリーロック／サザンロック | 1960–70年代 | 米南部・カントリーとの交差 |

### パンクとその後

| サブジャンル | 特徴 |
| --- | --- |
| パンクロック | 1970年代、短い曲・単純なコード・DIY。ラモーンズ、セックス・ピストルズ |
| ポストパンク | より内省的・実験的。ジョイ・ディヴィジョン、ザ・キュアー |
| ニューウェーブ | パンク以降のシンセ／ポップ寄り革新 |
| ゴシックロック | 暗く耽美なムード |
| ハードコアパンク | さらに速く攻撃的 |
| グランジ | 1990年代シアトル。汚れたギターと内省。ニルヴァーナ |
| オルタナティブロック | 主流への「もう一つの」ロックの総称。R.E.M.、レディオヘッド |
| インディーロック | 独立レーベル精神、多様なサウンド |
| シューゲイザー | 厚いギターの壁と埋もれたボーカル |
| エモ | 感情を前面に出したハードコア由来の流れ |
| ポストロック | 歌よりテクスチャと展開 |

### ヘヴィメタル系統

ハードロックから分化し、大音量・低音・ virtuoso なギターを特徴とする系統です。

| サブジャンル | 特徴 |
| --- | --- |
| ヘヴィメタル | 1970年代。ブラック・サバス、アイアン・メイデン |
| NWOBHM | 英国新世代メタル |
| スラッシュメタル | 高速・攻撃的。メタリカ、スレイヤー |
| デスメタル | グロウル、ブラストビート |
| ブラックメタル | 冷たく鋭い音色、ノルウェーなどで発展 |
| ドゥームメタル | 極端に遅いテンポと重さ |
| パワー／シンフォニックメタル | 旋律的、しばしばオーケストラ的 |
| メタルコア | メタル×ハードコア。ブレイクダウンが目印 |
| ヌメタル | 1990年代、ヒップホップやオルタナとの交差 |
| フォークメタル／ヴァイキングメタル | 民族旋律や北欧テーマとの融合 |

日本では**ヴィジュアル系**（外見と世界観を強く打ち出すロック／メタル）も独自の位置を占めます。

## 8. ポップス

**ポップ（Pop）**は「大衆に届く、キャッチーな歌もの」の総称です。ロックやR&B、電子音楽など他系統の要素を吸収し続けるため、音の定義より**歌・フック・短めの楽曲・チャート**という機能で捉えるとわかりやすいです。

| サブジャンル | 特徴 |
| --- | --- |
| 伝統的ポップ／ティンパンアレー | 20世紀前半のショーチューン、クロナー |
| バブルガムポップ | 1960年代、ティーン向けの甘いポップ |
| ダンスポップ | 強いビート＋歌。マドンナ、レディー・ガガ |
| シンセポップ | 1980年代、シンセが主役 |
| ユーロポップ／ユーロダンス | 欧州発の明るいダンスポップ |
| ティーンポップ／アイドルポップ | アイドル産業と結びついた歌とパフォーマンス |
| アートポップ | 実験性・コンセプトを持つポップ |
| ハイパーポップ | 2010年代後半〜、電子音を極限まで歪めたネット世代のポップ |
| シティポップ | 日本、1970–80年代の都会的AOR／ソフトロック。海外で再評価 |
| J-POP | 日本語の大衆ポップの市場ラベル（後述） |
| K-POP | 韓国、1990年代〜。訓練・映像・ダンスを一体化したグローバルポップ |
| C-POP（マンドポップ／カントポップ） | 中国語圏のポップ |

関連ラベルとして **AOR、アダルト・コンテンポラリー、パワーポップ、ポップロック** などもあります。

## 9. ヒップホップ

**発祥**：1970年代、ニューヨーク・ブロンクス。  
文化としては **DJing・ラップ（MC）・ブレイクダンス・グラフィティ** の四要素。音楽としては、ブレイクビーツのループ、サンプリング、韻とフロウが中心です。ファンク、ソウル、ディスコ、ジャズ、ダブから栄養を取っています。

| サブジャンル | 特徴 |
| --- | --- |
| オールドスクール | 1970–80年代中頃。パーティーラップ、シンプルなブレイク |
| ブームバップ | 1980–90年代。重いキック／スネアと緻密な韻 |
| ギャングスタラップ | ストリートの暴力・貧困を描く。N.W.A、2Pac など |
| Gファンク | 西海岸、ファンクのシンセとグルーヴ |
| ジャズラップ／オルタナティブ | ジャズサンプル、意識的・実験的な詞 |
| サザンヒップホップ | 南部。クランク、バウンスなど地域色 |
| トラップ | 2000年代アトランタ発。808ベースと細かいハイハット。世界のポップに浸透 |
| ドリル | シカゴ発、のち英国ドリルへ。暗い内容と独特のフロウ |
| マンブルラップ | 音節を曖昧にしたメロディックな歌い方 |
| クラウドラップ／エモラップ | 夢見るような、または感情的な歌ものラップ |
| ローファイヒップホップ | ノイズを残したBGM的ビート。nujabes などの影響も大きい |
| フォンク | メンフィスラップ由来の暗いドライブ感。SNSで拡散 |
| グラライム | 英国、UKガレージとラップの交差 |

日本では **J-ラップ（日本語ラップ）** が1990年代以降に独自のフロウとシーンを育てています。

## 10. 電子音楽・ダンスミュージック

電子楽器・録音技術・クラブを舞台に発展した系統です。実験音楽としての流れと、踊るための流れが並行しています。

### 実験・聴取向け

| ジャンル | 特徴 |
| --- | --- |
| ミュジーク・コンクレート | 録音物を素材にする1940年代フランスの実験 |
| クラフトワーク以降の電子ポップ | ドイツ電子音楽。テクノポップ、YMO などへ波及 |
| アンビエント | 環境として機能する音。ブライアン・イーノ |
| ニューエイジ | 瞑想・ヒーリング寄りの穏やかな電子／アコースティック |
| IDM | 「踊るためだけではない」複雑な電子音楽 |
| ドローン／ノイズ | 持続音、ノイズそのものを音楽にする |
| ヴェイパーウェイヴ／シンセウェイヴ | 懐古的な電子美学、ネット発 |

### クラブ／EDM 系

| ジャンル | 発祥の目安 | 特徴 |
| --- | --- | --- |
| ハウス | 1980年代シカゴ | 4つ打ちキック。ウェアハウスというクラブ名が語源とされる |
| ディープハウス | よりソウルフルで奥行きのあるハウス |
| テクノ | 1980年代デトロイト | 機械的・反復的。工業都市とアフロフューチャリズム |
| トランス | 1990年代ドイツなど | 高BPM、レイヤーされたシンセ、恍惚感 |
| ドラムンベース／ジャングル | 1990年代英国 | 160–180BPM前後の高速ブレイクと重いベース |
| ダブステップ | 2000年代ロンドン | ウォブルベース、ハーフタイムのグルーヴ |
| ガレージ（UK）／グライム | 英国のクラブ／MC文化 |
| ハードスタイル／ガバ | 高速で硬いキック |
| EDM（狭義） | 2010年代の大型フェス向け電子ダンスの商業的総称 |
| フューチャーベース | うねるシンセと感情的なボーカルチョップ |

**EDM** という言葉は、本来「電子ダンス音楽全般」ですが、日本語圏では2010年代の大型フェス系（ビッグルーム、プログレッシブハウス等）を指すことが多いです。

## 11. フォーク・カントリー

### フォーク

本来は各地の**民謡・口承音楽**の総称です。1960年代のフォークリバイバル（ボブ・ディラン、ジョーン・バエズなど）以降、「アコースティックな弾き語り＋社会的な詞」という意味でも使われます。

派生：フォークロック、インディーフォーク、プロテストソング、ネオフォーク、サイケデリックフォークなど。

### カントリー

**発祥**：米国南部、1920年代頃に録音産業の中で確立。  
アパラチアの民謡、ブルース、西部の歌が混ざった農村／労働者の音楽。バンジョー、フィドル、スティールギターなどが象徴的です。

| サブジャンル | 特徴 |
| --- | --- |
| ホンキートンク | 酒場のカントリー |
| 西部劇音楽／ウェスタンスウィング | 西部イメージ、ジャズのスウィングとの交差 |
| ブルーグラス | 高速アコースティック。ビル・モンロー |
| アウトロー・カントリー | 1970年代、商業カントリーへの反抗 |
| カントリーポップ | ポップチャート向け。テイラー・スウィフト初期など |
| アメリカーナ | カントリー・フォーク・ブルース・ロックのルーツ総称 |
| オルタナティヴ・カントリー | インディー／ロック寄りの再解釈 |

## 12. カリブ海（スカ・レゲエなど）

ジャマイカを中心に、米国R&Bの影響から独自のオフビート文化が育ちました。

```text
メント（ジャマイカ民謡）
  → スカ（1950–60年代、速いアップビート＋ブラス）
    → ロックステディ
      → レゲエ（1960年代後半〜、ゆったりしたオフビート、ラスタファリの精神性）
        ├─ ルーツレゲエ
        ├─ ダブ（音響操作・空間系エフェクトの先駆け）
        ├─ ラヴァーズロック
        └─ ダンスホール（デジタルビート＋DJ／MC）
              └─ レゲトン（プエルトリコ等、デムボウリズム。世界的ポップへ）
```

代表：ボブ・マーリー（レゲエ）、スカタライツ（スカ）、シャバ・ランクス（ダンスホール）、ダディ・ヤンキー（レゲトン）など。  
ダブの音響思想は、電子音楽・ヒップホップ・ポストパンクにも深く影響しています。

## 14. アフリカ・中東・アジアなどの地域音楽

「ワールドミュージック」は1980年代以降の市場ラベルで、中身はきわめて多様です。代表的な幹だけ挙げます。

### アフリカ

| ジャンル | 地域 | 特徴 |
| --- | --- | --- |
| アフロビート | ナイジェリア | フェラ・クティ。ジャズ／ファンク×ヨルバ音楽 |
| アフロビーツ | 西アフリカ、2000年代〜 | 現代のポップ／ダンス。Burna Boy、Wizkid など |
| ハイライフ | ガーナなど | ギターとブラスの軽快な大衆音楽 |
| コンゴレス・ルンバ／スクース | 中部アフリカ | 流麗なギター |
| ライ | アルジェリア | 都市の若者の歌 |
| アマピアノ／グコム | 南アフリカ | 近年のグローバルなクラブ音楽 |
| クワイト／クドゥロ | 南部アフリカ／アンゴラ | ダンスと電子ビート |

### 中東・北アフリカ

アラビック・ポップ、ライ、マカームに基づく古典、ベルベルの民謡など。旋法と装飾的な歌唱が特徴です。

### 南アジア・東南アジア

- **フィルミ／ボリウッド音楽**（インド）：映画と一体の大衆歌謡。

## 15. 日本の音楽

日本の音楽は、(A) 古典・伝統、(B) 近代の大衆歌謡、(C) グローバルなポピュラー音楽の日本語シーン、の三層で見ると整理しやすいです。

### A. 伝統音楽（純邦楽・民俗）

| ジャンル | 特徴 |
| --- | --- |
| 雅楽 | 宮廷音楽。国風歌舞＋唐楽・高麗楽。世界最古級の管弦楽の一つ |
| 声明 | 仏教の声楽 |
| 能楽 | 謡と囃子。能・狂言 |
| 琵琶楽 | 平曲、薩摩琵琶、筑前琵琶など語りもの |
| 三味線音楽 | 義太夫節（文楽）、長唄（歌舞伎）、常磐津・清元、端唄・小唄など |
| 三曲 | 地歌、箏曲、尺八 |
| 民謡 | 追分、音頭、甚句、馬子唄、沖縄民謡など地域ごと |
| アイヌの音楽 | ユカㇻなどの口承 |
| 琉球音楽 | 三線を中心とする独自の音階と歌 |

### B. 近代の大衆音楽

| ジャンル | 特徴 |
| --- | --- |
| 演歌 | こぶし、五音的な旋律、義理・人情・望郷。美空ひばり、北島三郎など |
| 歌謡曲 | 大正〜昭和の流行歌の総称。後のJ-POPの土壌 |
| グループ・サウンズ | 1960年代、エレキポップバンド |
| フォーク／ニューミュージック | 1970年代、シンガーソングライター文化 |
| シティポップ | 1970–80年代、都会的で洗練されたAOR的サウンド |
| アイドル歌謡 | テレビと連動したアイドル産業の歌 |

### C. 現代の日本語ポピュラー

| ジャンル／ラベル | 特徴 |
| --- | --- |
| J-POP | 1990年代以降の邦楽ポップ市場の総称。音はロック〜R&B〜電子まで幅広い |
| 邦ロック（J-ROCK） | 日本語ロック。オルタナ、ビジュアル系、バンドブームの系譜 |
| アニソン | アニメの主題歌・挿入歌。用途ラベルだが独自のメロディ感覚と熱量がある |
| ボカロ | VOCALOID等の合成音声を前提にした創作文化。ジャンルというより制作・流通の生態系 |
| ゲームミュージック | チップチューンからオーケストラまで。日本が世界的に強い領域 |
| 日本語ラップ | 日本語の音韻に合わせたフロウ |
| テクノポップ | YMO以降の電子ポップの流れ |

「J-POP」はロックもヒップホップも含みうる**市場カテゴリ**であり、「ポップス」という音の系統とは層が違う、という点が重要です。

## 16. 宗教・舞台・応用音楽

音の系統というより、**場と機能**でまとまるグループです。

| カテゴリ | 内容 |
| --- | --- |
| 宗教音楽 | グレゴリオ聖歌、ゴスペル、賛美歌、仏教声明、スーフィー音楽、聖歌など |

## 17. ジャンル間の主なつながり

系統をまたぐ「橋」をいくつか挙げます。ここを知ると、個別ジャンル名を暗記するより音楽が立体的に見えます。

| つながり | 内容 |
| --- | --- |
| ブルース → ロック | ロックンロールの中核 |
| ブルース／ラグタイム → ジャズ | 即興音楽の土壌 |
| ゴスペル → ソウル → 現代R&B | 歌唱法の直系 |
| ファンクのブレイク → ヒップホップ | DJが「美味しい部分」をループした |
| ディスコ → ハウス | クラブの4つ打ち文化 |
| ダブ → 電子音楽／ヒップホップ | リミックスと空間処理の思想 |
| ジャズ → ヒップホップ | サンプリングとジャズラップ |
| ソウル／ハウス → テクノ／EDM | ダンスフロアの連続性 |
| スカ／レゲエ → パンク | 2トーン・スカ、レゲエパンク |
| カントリー × R&B → ロックンロール | 1950年代の融合 |
| トラップ → グローバルポップ | 2010年代以降、K-POPやラテン、J-POPまでリズムが浸透 |
| クラシックの和声・編曲 → ポップ／映画音楽 | オーケストレーションの技術 |

新しいジャンルは、たいてい「既存の二つの系統の交差点」で生まれます。

## おわりに

ジャンルは「正解の棚」ではなく、**聴く・探す・語るための地図**です。まずは大きな幹（クラシック、ブルース、ジャズ、ロック、ポップ、ヒップホップ、電子、ラテン、日本の伝統と歌謡）を押さえ、気になった枝だけ降りていく、という使い方が向いています。

本資料に載せきれなかった細分（メタルだけでも数十、電子音楽は数百）は、各系統のWikipedia項目や AllMusic のサブジャンル一覧からさらに辿れます。
