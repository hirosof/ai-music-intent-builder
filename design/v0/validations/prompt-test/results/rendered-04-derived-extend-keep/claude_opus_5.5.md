## 注意事項

- **要素の順序と元曲の保持（§5-3 と §7）**：§7 では元曲のスタイル文を「変更しない」ことが求められています。そのため、元曲の文言は語順も含めてそのまま先頭に置き、§5-3 の順序（ジャンル・様式 → 声 → テンポ → 情緒 → 楽器 → 展開 → 質感）は追加した要素にだけ適用しました。元曲の文の中では、要素の並びがこの基本順と一致していません。
- **「延長」と「山型」の解釈**：延長は曲の途中から続ける操作ですが、山型（起承転結）は延長で生成される部分の中で完結する流れとして書きました。質問はせずにこの解釈を採っています。
- **ループ再生の表現**：尺を前提にしない書き方として、「結びから切れ目なく冒頭へ戻る」という形で表しました。延長元の冒頭とうまくつながるかは、生成結果に左右されます。
- **除外語の英訳**：除外語は「保持」の指定なので、「歪んだ音色」の直訳である distorted tones だけを記載し、distorted guitar などへの展開はしていません。
- 実在の固有名詞は、入力にも出力にも含まれていません。
