## 案 1 / 3

**基本プロンプト**

```
Japanese orchestral, Japanese flute, taiko drum, wordless chorus, dark and intense, cinematic reverb
```

日本語訳：日本風オーケストラ、篠笛、和太鼓、言葉のない合唱、暗く緊迫、映画的残響

**詳細プロンプト**

```
Japanese orchestral with shakuhachi and shinobue leading the melody, taiko drum driving the rhythm in powerful strikes. Dark and tense atmosphere with unwavering intensity. Large ensemble with strings (violin, cello, kontrabass) providing deep harmonic support. Wordless vocal choir adds ethereal texture without lyrics. Fast-paced, relentless forward momentum. Cinematic spatial reverb creates depth and grandeur. Clear studio sound with natural, full-bodied mix.
```

日本語訳：
 篠笛と尺八がメロディを先導する日本風オーケストラ。力強い打ちの和太鼓がリズムを駆動。暗く緊迫した雰囲気で揺らがぬ強度を保つ。弦楽器（ヴァイオリン、チェロ、コントラバス）が深い調和的支えを提供する大編成。言葉のない合唱がリリカルなテクスチャーを加える。速いテンポ、休まぬ前進の勢い。映画的な空間的残響が奥行きと壮大さを演出。クリアなスタジオ音質で自然で豊かなミックス。

**この案の狙い**
 古典的な和風の趣を残しつつ、深い弦楽器による支えで暗さと沈着さを強調。ボス戦での「強敵感」を最大化する案。

**スタイルを除外**

```
Celtic, electric guitar, distorted tones
```

## 案 3 / 3

**基本プロンプト**

```
Japanese orchestral, shakuhachi, taiko, wordless vocals, dark intense, deep strings, cinematic reverb
```

日本語訳：日本風オーケストラ、尺八、和太鼓、言葉のないボーカル、暗く激烈、深い弦楽、映画的残響

**詳細プロンプト**

```
Japanese orchestral centered on shakuhachi's haunting tones and taiko drum's relentless strikes. Dark, pressing intensity without release. Large ensemble dominated by deep strings (cello, kontrabass, viola) creating a foundation of dread. Shinobue adds piercing melodic counterpoint. Fast tempo with building momentum. Wordless vocal choir contributes airy, floating texture against the heavy orchestral bed. Gong and lower percussion layer add weight and mystery. Cinematic reverb with pronounced spatial depth. Clean studio production emphasizing clarity of each instrument layer.
```

日本語訳：
 尺八の恐ろしい音色とリズミカルで止まぬ和太鼓を中心とした日本風オーケストラ。暗く、圧迫的な激烈さで解放なし。深い弦楽器（チェロ、コントラバス、ヴィオラ）が恐怖の基礎を作る大編成。篠笛が鋭いメロディック対位法を加える。速いテンポで増す勢い。言葉のない合唱が軽やかで浮遊するテクスチャーで重いオーケストラ層に対抗。ゴングと低域打楽器がレイヤーを加えて重厚感と神秘性を増す。著しい空間的奥行きを持つ映画的残響。各楽器レイヤーの明瞭さを強調するクリアなスタジオ制作。

**この案の狙い**
 尺八の独特な音色を前面に出し、より暗く圧迫的な雰囲気を構築。低域の弦楽と打楽器で「不気味さ」を強調する最も緊張度の高い案。

**スタイルを除外**

```
Celtic, electric guitar, distorted tones
```

- 「映画的な広い残響」は、英語では「cinematic reverb」「cinematic spatial reverb」で統一しました。
- 3案の差は、主に「伴奏楽器の選択」と「明暗の強度」で設けました。指定項目は全案で保持されています。
