# 案 1 / 3(弦楽器主体)

**基本プロンプト**

```
Epic orchestral with Japanese traditional influence, wordless choir, shakuhachi and shinobue lead, taiko drums, tense and solemn atmosphere, fast tempo, cinematic strings
```

和風の要素を持つ壮大なオーケストラ、言葉のない合唱、尺八と篠笛が主旋律、和太鼓、緊迫感と荘厳さ、速いテンポ、映画的な弦楽器。

**詳細プロンプト**

```
Epic cinematic orchestral meets traditional Japanese style, large-scale ensemble score for an intense game boss battle. Wordless choir chants above the orchestra, adding sacred weight. Fast, driving tempo sustains relentless, unbroken energy, built for seamless continuous looping. Tense, dark, solemn, majestic atmosphere that keeps continuously intensifying. Shakuhachi and shinobue carry piercing main melodic lines over a sweeping string section of violins, cellos and double basses building sustained harmonic tension, low horns and trombones swelling for gravity, subtle koto accents coloring the texture. Wadaiko taiko drums drive the powerful rhythmic pulse alongside orchestral percussion. Clean, high-fidelity cinematic studio production, wide cinematic reverb, natural balanced mix.
```

和の様式を帯びた壮大なシネマティック・オーケストラによる、ゲームの激しいボス戦用の大編成楽曲。言葉のない合唱がオーケストラの上に重なり、神聖な重みを加える。速く駆り立てるテンポが途切れない緊張感を保ち、継続的なループ再生に適した構成となっている。緊迫感・暗さ・荘厳さが絶えず高まり続ける雰囲気。尺八と篠笛が鋭い主旋律を奏で、その下でヴァイオリン・チェロ・コントラバスによる弦楽セクションが持続的な緊張感を築き、低音のホルンとトロンボーンが重厚さのために盛り上がり、箏の音が繊細な彩りを添える。和太鼓がオーケストラ・パーカッションとともに力強いリズムを牽引する。クリアで高品質なシネマティック・スタジオ・プロダクション、広い映画的な残響、自然なバランスのミックス。

**この案の狙い**：伴奏楽器を弦楽セクション中心に構成し、持続する緊張と重厚感を弦の厚みで表現する案。3案の基準形として、伴奏を最もオーケストラらしい弦主体で組み立てている。

**スタイルを除外**

```
electric guitar, Celtic, nostalgic, distorted tone
```

# 案 3 / 3(和楽器混成・室内オーケストラ寄り)

**基本プロンプト**

```
Epic orchestral with Japanese traditional influence, wordless choir, shakuhachi and shinobue lead, taiko ensemble, tense and solemn, fast tempo, koto and biwa textures
```

和風の要素を持つ壮大なオーケストラ、言葉のない合唱、尺八と篠笛が主旋律、太鼓アンサンブル、緊迫感と荘厳さ、速いテンポ、箏と琵琶の質感。

**詳細プロンプト**

```
Epic cinematic orchestral meets traditional Japanese style, large-scale ensemble score for an intense game boss battle. Wordless choir chants above the orchestra, adding sacred weight. Fast, driving tempo sustains relentless, unbroken energy, built for seamless continuous looping. Tense, dark, solemn, majestic atmosphere that keeps continuously intensifying. Shakuhachi and shinobue carry piercing main melodic lines woven with koto and biwa textures over a supporting string section, deepening the Japanese character. Layered wadaiko taiko ensemble of varying drum sizes drives dense, powerful rhythmic depth alongside orchestral percussion. Clean, high-fidelity cinematic studio production, wide cinematic reverb, natural balanced mix.
```

和の様式を帯びた壮大なシネマティック・オーケストラによる、ゲームの激しいボス戦用の大編成楽曲。言葉のない合唱がオーケストラの上に重なり、神聖な重みを加える。速く駆り立てるテンポが途切れない緊張感を保ち、継続的なループ再生に適した構成となっている。緊迫感・暗さ・荘厳さが絶えず高まり続ける雰囲気。尺八と篠笛が鋭い主旋律を奏で、箏と琵琶の質感が織り込まれ、支える弦楽セクションの上で和の色彩を深めている。大小さまざまな太鼓からなる和太鼓アンサンブルが重層的に重なり、オーケストラ・パーカッションとともに密度の高い力強いリズムを牽引する。クリアで高品質なシネマティック・スタジオ・プロダクション、広い映画的な残響、自然なバランスのミックス。

**この案の狙い**：伴奏楽器に箏・琵琶や太鼓アンサンブルを重ね、和楽器の比重を最も高くした案。オーケストラでありながら和の質感を最も深く前面に出している。

**スタイルを除外**

```
electric guitar, Celtic, nostalgic, distorted tone
```

## 注意事項

- 「明暗」はお任せ項目で、導出根拠が「情緒」からの間接的な推論(緊迫・荘厳→暗め)にとどまるため、本来は確認したかった箇所です。§1の指示に従い質問せず、情緒に整合する解釈として判断しました。
- 差を付ける軸は「伴奏・支える楽器」(お任せ項目)に設定しました。これも本来は複数の候補(テンポの微妙な違い、音質の違いなど)があり得ましたが、§7-3「今回の差の付け方」が「あなたが選んでよい」としていたため、質問せず判断しています。
