# 注意事項

- 「声を入れない」の既定値は、合唱やハミングなどの声の要素を足さないという意味で解釈し、スタイル欄では声について触れませんでした。案3の終盤の「重なるハーモニー」は楽器的な重なりを指す表現ですが、Suno側でコーラスとして解釈される可能性があります。気になる場合はこの語を削除してください。
- 案1・案2は、Suno側で書き換えられる前提で、核となる要素を前方に置き、細部は最小限にとどめました。
- 案2の基本プロンプトの「slap-free」は否定的な表現に近いため、気になる場合は「melodic bass」のみに差し替えてください。
