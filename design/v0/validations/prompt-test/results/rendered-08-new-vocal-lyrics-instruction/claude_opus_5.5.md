**スタイルを除外**

```

```

## 注意事項

- **§8-2 と §6・§5-3 の食い違い**
  - 食い違いの内容：§8-2 では、詳細プロンプトに「テンポ」「声の扱い」を含めるよう求めています。一方、§6 では BPM が「指定しないまま残す」、声の扱いが「触れないまま残す」です。さらに §5-3 では、歌唱の質感をスタイル欄に書かないよう求めています。
  - 採った方針：要件表（構造化された個別指定）と §5-3 を優先しました。テンポは「mid-tempo」という定性的な語だけで表現し、BPM の数値は書いていません。声・歌唱にはスタイル欄で一切触れていません。
- **歌詞の分量の書き方**
  - §7 では、分量を長さに見合うものにするよう求めています。一方、§5-2 では長さの値を本文に書かないよう求めています。
  - 作詞AIへの指示が §5-2 の「本文」に含まれるかどうか判断が分かれるため、数値は書かず「短めの1曲に収まる分量」と表現しました。
- **「スタイルを除外」欄の語の選び方**
  - 「使用しない：緊迫感」は、英語で `tension` と表記しました。
