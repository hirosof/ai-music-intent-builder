## 注意事項

- 元曲のスタイルには §6 の指定のうち「言葉のない合唱」「速い」「強い」「大編成」「山型の展開」「ループ再生」「映画的な広い残響」が含まれていないため、これらを追加しました。元曲の語句と §6 の間に矛盾はありませんでした。
- 元曲の語句の並び（ジャンル → 打楽器 → 主旋律 → 雰囲気 → 用途）は §5-3 の順序と異なるため、語句自体は変えずに順序だけ並べ直しました。
- 元曲の「Traditional」は様式（和風）を表す語と解釈し、年代・時代感の「modern game score」とは別の軸として併記しました。
- 案の差を付ける軸は「伴奏・支える楽器の重心」（洋楽器寄り／和楽器寄り／打楽器寄り）を選びました。
- 展開の形「山型（起承転結）」は、構成を指定しないまま残すため、セクション名を使わず4段階の流れとして記述しました。ループ再生との両立は seamlessly loopable flow で表し、長さやループの尺には触れていません。
