## 補完一覧

| 項目 | 決めた内容 | 理由 |
| --- | --- | --- |
| 派生元スタイルへの近さ | 案ごとに異なる | 判断を委ねられたため、案の差を付ける軸として使用（各案の「狙い」を参照） |
| 用途の詳細 | 第2形態の局面 | 用途「ボス戦の第2形態」から導いた（案ごとの描写の強さは「近さ」の軸に従う） |
| 年代・時代感 | 現代的なゲーム音楽（modern game score） | ボス戦用のオーケストラ曲として最も一般的な時代感を主ジャンルから導いた |
| 副ジャンル | 指定しないまま残した | 指示どおり |
| 明暗 | 暗め（dark） | 基調となる情緒「緊迫」「荘厳」から導いた |
| 伴奏・支える楽器 | 案ごとに異なる | 「近さ」の軸に連動して編成を変えた（各案の「狙い」を参照） |
| BPM の目安 | 指定しないまま残した | 指示どおり（テンポ感「速い」のみ記述） |
| 構成（セクションの並び） | 指定しないまま残した | 指示どおり |
| 音質・録音の質感 | クリアなスタジオ品質（clear studio-quality recording） | 手がかりなしのため、指示された扱いに従った |
| その他・補足 | 指定しないまま残した | 指示どおり |

## 注意事項

- 元曲のスタイルには §6 の指定のうち「言葉のない合唱」「速い」「強い」「大編成」「山型の展開」「ループ再生」「映画的な広い残響」が含まれていないため、近さに関係なく全案に追加しました。元曲の語句と §6 の間に矛盾はありませんでした。
- 「どの程度近づけるか」の判断を案ごとに変える形で示しました（案1：元曲に最も近い／案2：中間／案3：最も離れる）。指定項目の内容はどの案でも同じです。
- 案1・案2 では元曲の語句を変えずに §5-3 の順序へ並べ直しました。案3 では元曲の語句を §6 の範囲で言い換えています（例：Traditional Japanese orchestral → Japanese-style orchestral battle music）。
- 元曲の「Traditional」は様式（和風）を表す語と解釈し、年代・時代感の「modern game score」とは別の軸として併記しました。
- 展開の形「山型（起承転結）」は、構成を指定しないまま残すため、セクション名を使わず4段階の流れとして記述しました。ループ再生との両立は seamlessly loopable で表し、長さやループの尺には触れていません。
