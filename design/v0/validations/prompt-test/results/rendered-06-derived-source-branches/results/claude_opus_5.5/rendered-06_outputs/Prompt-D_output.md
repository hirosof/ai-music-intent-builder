## 注意事項

- 「§6 との差分は小さく押さえてください」は、「元曲のスタイルに §6 を反映する際の変更量を小さくする」という意味に解釈しました。ただし §3 の優先順位上、「指定」の項目（言葉のない合唱、速い、強い、大編成、山型の展開、ループ再生、映画的な広い残響）は派生元との整合より優先されるため、すべて追加しています。
- 差分を小さくするため、お任せ項目のうち「用途の詳細」「年代・時代感」は記述していません（上表参照）。
- 元曲の語句の並び（ジャンル → 打楽器 → 主旋律 → 雰囲気 → 用途）は §5-3 の順序と異なるため、語句自体は変えずに順序だけ並べ直しました。
- 案の差は伴奏の1要素（弦楽／箏／低音金管）のみに絞りました。そのため基本プロンプトは3案とも同一です（基本プロンプトは核となる要素のみで、伴奏を含めていないため）。
- 展開の形「山型（起承転結）」は、構成を指定しないまま残すため、セクション名を使わず短い流れとして記述しました。長さやループの尺には触れていません。
