#### 詳細プロンプト

Plaintext

```
ambient, downtempo, slow tempo, contemplative, tranquil, meditative mood, warm analog synthesizer carrying smooth melodic phrases, soft Rhodes electric piano playing sparse background chords, deep sustained sub-bass foundation, subtle tape hiss and gentle field recordings providing a light organic pulse, slow evolving soundscape, spacious acoustic reverberation, wide stereo field, clear studio quality, natural mix
```

**詳細プロンプトの日本語訳:**

アンビエント、ダウンテンポ、スローテンポ、瞑想的、静穏、メディテーティブなムード、滑らかな旋律を奏でる温かみのあるアナログシンセサイザー、まばらなコードを響かせる柔らかなローズ・エレクトリックピアノ、重層的な低域を支える持続的なサブベース、微かなテープヒスと穏やかなフィールドレコーディングによる軽快でオーガニックなパルス、緩やかに変化する音景、広大な残響空間、ワイドなステレオ音場、クリアなスタジオ品質、自然なミックス。

#### この案の狙い

指定の「アンビエント」から、瞑想的かつ温かみのあるシンセ主体のサウンドスケープを構築しました。ビート感を前面に出さず、フィールドレコーディングやテープヒスによる微細なパルスをリズム要素として配置することで、アンビエント特有の浮遊感と心地よい質感の両立を狙っています。

### 補完一覧

| **項目**         | **決めた内容**                                         | **理由**                                                     |
| ---------------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| 用途             | 特定の用途を想定しない楽曲                             | 指定項目から特定の用途を限定的に導く必然性がないため。       |
| 年代・時代感     | 指定しない                                             | 時代を固定せず普遍的なアンビエントの音響空間を維持するため。 |
| 基調となる情緒   | 静穏・瞑想的（tranquil, meditative）                   | アンビエントの標準的な情緒として最も調和しやすいため。       |
| 強度             | 中程度（moderate）                                     | 手がかりなしの指示に従い、極端な抑揚を避けた中程度に設定。   |
| 明暗             | 中間（neutral）                                        | 手がかりなしの指示に従い、明るすぎず暗すぎないニュートラルに設定。 |
| 主旋律を担う楽器 | 温かみのあるアナログシンセサイザー                     | アンビエントにおいて滑らかで持続力のある旋律を担うのに適しているため。 |
| 伴奏・支える楽器 | 柔らかなエレピ（Rhodes）とサブベース                   | シンセの旋律を邪魔せず、空間の広がりと安定感を両立させるため。 |
| リズムの担い手   | 微細なパルス（テープヒス・フィールドレコーディング音） | 打楽器による強い拍を避け、アンビエントの浮遊感を保つため。   |
| 編成の規模       | 小編成（minimal layers）                               | 音の隙間と静けさを活かした音響構成にするため。               |
| テンポ感         | スローテンポ（slow tempo / downtempo）                 | 静穏な情緒を維持するため、穏やかでゆったりとした速度感を設定。 |
| 空間の質感       | 広大な空間性・深いリバーブ（spacious reverb）          | アンビエントの特徴である奥行きと没入感を生み出すため。       |
| 音質・録音の質感 | クリアなスタジオ品質（clear studio quality）           | 指示に基づき、高品位なスタジオクオリティを忠実に適用。       |
| ミックスの方向性 | 自然なミックス（natural mix, wide stereo field）       | 指示に基づき、広がりと調和を重視した自然な配置を設定。       |

※「指定しないまま残す」とされていた項目（用途の詳細、想定する聴取環境、副ジャンル、地域・文化の様式、BPMの目安、展開の形、構成、除外したい要素、その他・補足）は、ルールに従いプロンプトに含めず指定なしのまま残しています。

### 注意事項

- **リズムの担い手に関する判断:** リズムを「必ず決める」というルールに対し、アンビエントというジャンル特性（明確なドラムやパーカッションが入るとダウンテンポやチルアウトへ変質しやすい点）との兼ね合いが生じました。確認質問を行わない方針に従い、強い打楽器ではなく「フィールドレコーディングやテープの揺らぎによる微細なパルス」をリズム担い手として設定することで、インストのアンビエントとしての純度と要件の両立を図りました。
