# Suno v6 ボス戦BGM プロンプト作成結果

**用途**: ゲームのボス戦BGM（ループ再生）  
**形式**: インストゥルメンタル（歌詞なし）  
**主ジャンル**: オーケストラ（和風）

---

## 案 1 / 3：融合の美学

### 基本プロンプト

```
Japanese-orchestrated boss battle, shamisen and taiko-driven, cinematic grand hall ambience, fast-paced, non-lyrical choir texture
```

**日本語訳**  
日本的なボス戦オーケストラ、三味線と太鼓が駆動、映画的な広大なホールの残響、速いテンポ、言葉のない合唱の質感

### 詳細プロンプト

```
Japanese orchestral boss battle theme: Japanese bamboo flute (shakuhachi and shinobue) leads the urgent melody over deep strings and traditional taiko drums. Built on fast-paced tempo (135-145 BPM equivalent), sustained tension through relentless percussion and tremolo strings. Large ensemble with koto and Japanese cello supporting harmonies. Wordless chorus adds mystical intensity without lyrics. Cinematic reverb creates expansive hall space with clear, brilliant studio audio. Dramatic dynamic swells build without resolution, maintaining constant dread and power throughout. Japanese aesthetic merged with orchestral grandeur.
```

**日本語訳**  
日本的なボス戦オーケストラテーマ：日本の竹製フルート（尺八と篠笛）が緊迫したメロディを先導し、深いストリングスと伝統的な和太鼓の上に響く。速いテンポ（BPM 135-145相当）に基づき、絶え間ないパーカッションとトレモロ弦で持続する緊張感。琴と日本チェロが調和を支える大編成。言葉のない合唱が歌詞なしで神秘的な強度を加える。映画的な残響が広大なホール空間を作り出し、クリアで輝きのあるスタジオ品質。劇的な強弱の変化が解決なく繰り返され、一貫した恐怖と力を保つ。日本的美学とオーケストラの雄大さの融合。

### この案の狙い

和楽器を中心に据えながらオーケストラとの融合を強調。三味線と琴の支える力で「日本的」な厳密さを保ちつつ、西洋オーケストラの豊かさを活かした案です。

### スタイルを除外

```
Distorted sounds, electric guitar, Celtic, lyrical vocal, pentatonic limitations, eastern minor scales only
```

## 案 2 / 3：激烈の力学

### 基本プロンプト

```
Fierce Japanese orchestral clash, shakuhachi fury with taiko percussion assault, ominous hall reverb, high-tension sustained drive
```

**日本語訳**  
激しい日本のオーケストラの衝突、尺八の猛烈さと太鼓の激しい打撃、不吉なホール残響、緊張感の高い持続的な推進力

### 詳細プロンプト

```
Intense Japanese orchestral boss battle: Shakuhachi screams the main melody in rapid, aggressive articulation over massive taiko and o-daiko (large ceremonial drums) creating relentless rhythmic wall. Shinobue layers piercing countermelody. Fast, driving tempo with no breath, building dread through repetition. Large orchestral ensemble features deep bass viols, tremolo violins, and resonant brass undertones. Wordless choir hums underlying drone of power and foreboding. Cinematic reverb grants epic hall grandeur; brilliant, warm studio quality captures every detail. Constant dynamic pressure escalates threat through layered intensity rather than resolution. Japanese ferocity meets orchestral majesty.
```

**日本語訳**  
激烈な日本的オーケストラのボス戦：尺八が素早く攻撃的なアーティキュレーションでメインメロディを叫び、巨大な和太鼓と大太鼓（儀式用大型太鼓）が容赦ないリズムの壁を作る。篠笛が鋭い対旋律を重ねる。速いテンポで息継ぎなく、繰り返しで恐怖を構築。大編成オーケストラは深いバスヴィオール、トレモロ・ヴァイオリン、共鳴する金管の低音を特徴とする。言葉のない合唱が力と不吉さの基調となるドローンをハミングで唱う。映画的な残響が壮大なホール空間を賦与し、明るく暖かいスタジオ品質がすべての細部を捉える。一貫した動的圧力が解決ではなく層状の強度を通じて脅威を増す。日本的な激烈さがオーケストラの威厳と出会う。

### この案の狙い

より激しく、戦闘的な側面を前面に出した案。大太鼓の追加と「息継ぎなく」というフレーズで、休止なく押し寄せるボス戦の恐怖感を強調しています。

### スタイルを除外

```
Distorted sounds, electric guitar, Celtic, lyrical vocal, soft dynamics, gentle progression
```

## 案 3 / 3：神聖の王座

### 基本プロンプト

```
Sacred Japanese orchestral throne, solemn shakuhachi and taiko ceremony, reverent cathedral-like hall, majestic sustained tension
```

**日本語訳**  
神聖な日本のオーケストラの玉座、厳粛な尺八と太鼓の儀式、敬虔な大聖堂のようなホール、荘厳で持続する緊張

### 詳細プロンプト

```
Majestic Japanese orchestral boss throne: Shakuhachi delivers solemn, deliberate melody with ceremonial dignity over powerful taiko pulses that feel like a god's heartbeat. Shinobue adds sparse, holy countermelody. Controlled fast tempo maintains relentless majesty through precision rather than chaos. Large orchestra: deep resonant strings (cello and contrabass), sustained horn chords, Japanese zither (koto) for harmonic depth. Wordless choir intones sacred drone, adding ethereal spiritual presence. Cinematic reverb creates vast temple-like space with crystalline studio clarity. Dynamic waves build solemnity, never breaking tension—a procession of power and divinity rather than aggression. Japanese ceremonial grandeur fused with Western orchestral nobility.
```

**日本語訳**  
荘厳な日本的オーケストラの玉座：尺八が神聖な儀式的威厳を持つ厳粛で思慮深いメロディを奏で、力強い和太鼓の脈動が神の心臓の鼓動のように響く。篠笛が希少で神聖な対旋律を加える。制御された速いテンポが混乱ではなく精密さを通じて容赦ない雄大さを保つ。大オーケストラ：深く共鳴するストリングス（チェロとコントラバス）、持続する金管のコード、調和の深さのための日本の琴（箏）。言葉のない合唱が神聖なドローンを唱い、幻想的な精神的存在感を加える。映画的な残響が寺院のような広大な空間を作り出し、透明感のあるスタジオ品質を備える。動的な波が荘厳さを構築し、決して緊張を破らない—侵攻というより力と神性の行進。日本の儀式的雄大さと西洋的なオーケストラの高貴さの融合。

### この案の狙い

「荘厳」の側面を最大限に強調した案。和太鼓を「心臓の鼓動」と表現し、希少で精選された音構成により、神聖さと威厳を前面に出しています。

### スタイルを除外

```
Distorted sounds, electric guitar, Celtic, lyrical vocal, aggressive percussion, chaotic rhythm
```

## 補完・仮定一覧

| 項目 | 決めた内容 | 理由 |
|---|---|---|
| 用途の詳細 | ボス戦の各段階で緊張感を保つサスペンスフルなループ再生環境 | ゲームBGMのループ再生という用途から、持続的な張力が必須 |
| 伴奏・支える楽器 | 案ごとに異なる | 案1は琴と日本チェロで温かみ、案2は低音弦で凶悪さ、案3は箏で神聖さを実現 |
| 明暗 | 暗から中間への推移 | 緊迫と荘厳の情緒では暗さが基本だが、映画的な空間感で若干明るさを保つ |
| 音質・録音の質感 | 案ごとに異なる | 案1は「ウォーム」で包容力、案2は「ブリリアント」で鮮鋭さ、案3は「クリスタリン」で透明性を優先 |
| 年代・時代感 | 指定しないまま残す | オーケストラと和楽器の融合により、時代を超越した様式として設定 |
| BPMの目安 | 指定しないまま残す | Sunoの生成時判断に委ねる |
| 構成（セクションの並び） | 指定しないまま残す | 一定の緊張を保つという要件をSunoが最適に配置 |

## 注意事項

### 楽器名の英訳について

日本語の楽器名（尺八、篠笛、和太鼓、琴、三味線など）は英語表記（shakuhachi, shinobue, taiko等）に統一しました。Sunoでの認識精度を考慮した判断です。

### 「言葉のない合唱」の表現

歌詞がないインストゥルメンタル条件を守るため、「wordless choir」「voiceless humming」など、歌唱ではなく楽器的な声の使用として表現しています。

### 3案の差別化軸

「音響キャラクター」を軸に選びました。
- **案1**: 融合と温かみ
- **案2**: 激烈さ
- **案3**: 神聖さ

同じ指定要素を異なる解釈で実現する差別化です。

## 使用上の注意

各プロンプトをSuno v6のアドバンスドモードで使用する際：

1. **詳細プロンプト**をスタイル欄に貼り付けてください
2. **スタイルを除外**の内容を、対応する除外欄に貼り付けてください
3. 歌詞欄は**空白のまま**にしてください（インストゥルメンタル条件）
4. その他の設定は以下を参照：
   - 長さ: 3:00
   - バリエーション: 標準
   - 奇抜さ: 50%
   - スタイルの影響: 50%
   - Max モード: オフ
